## מבוא

ממשק מגדיר התנהגות: רשימה של פעולות בלי מימוש. מחלקה שמממשת אותו מתחייבת לכתוב את כל הפעולות. במשימה הזו תכתבו ממשק של דבר שאפשר לנגן, שתי מחלקות שמממשות אותו, וממשק נוסף שרק אחת מהן מממשת.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: הממשק IPlayable

כתבו ממשק `IPlayable` עם שתי פעולות, בלי גוף: `Play` שמחזירה מחרוזת, ו-`GetSeconds` שמחזירה מספר שלם. לפי המוסכמה שם של ממשק מתחיל באות I.

חתימה:

```csharp
interface IPlayable
{
    string Play();
    int GetSeconds();
}
```

> **רמז:** בממשק לא כותבים הרשאת גישה לפעולות, והן ציבוריות מעצם הגדרתן.

### שלב 2: המחלקה Song

כתבו מחלקה `Song` שמממשת את `IPlayable`, עם תכונות פרטיות `title` ו-`seconds`, ובנאי שמקבל אותן. `Play` מחזירה `Playing song` ואחריו רווח והשם. הפעולות של הממשק חייבות להיות `public`.

חתימה:

```csharp
class Song : IPlayable
public Song(string title, int seconds)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Song("Hallelujah", 240).Play()` | `Playing song Hallelujah` |
| `new Song("Hallelujah", 240).GetSeconds()` | `240` |

### שלב 3: ממשק נוסף: IShareable

כתבו ממשק `IShareable` עם פעולה אחת: `Share`, שמחזירה מחרוזת. כתבו מחלקה `Video` שמממשת את שני הממשקים, `IPlayable` ו-`IShareable`. יש לה תכונות פרטיות `title` ו-`seconds`. `Play` מחזירה `Playing video` ואחריו רווח והשם. `Share` מחזירה `Sharing` ואחריו רווח והשם.

חתימה:

```csharp
interface IShareable
class Video : IPlayable, IShareable
public Video(string title, int seconds)
public string Share()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Video("Cats", 30).Play()` | `Playing video Cats` |
| `new Video("Cats", 30).Share()` | `Sharing Cats` |

> **רמז:** מחלקה יכולה לרשת ממחלקה אחת, אבל לממש כמה ממשקים. מפרידים ביניהם בפסיק.

### שלב 4: נגינה של כולם

כתבו בתוך `Program` פעולה סטטית שמקבלת מערך של `IPlayable` ומדפיסה, בשורה נפרדת לכל פריט, את התוצאה של `Play`.

חתימה:

```csharp
static void PlayAll(IPlayable[] items)
```

> **רמז:** המערך יכול להכיל גם שירים וגם סרטונים, כי כולם מממשים את הממשק.

### שלב 5: משך כולל

כתבו פעולה סטטית שמחזירה את סכום השניות של כל הפריטים במערך.

חתימה:

```csharp
static int TotalSeconds(IPlayable[] items)
```

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        IPlayable[] items = new IPlayable[3];
        items[0] = new Song("Hallelujah", 240);
        items[1] = new Video("Cats", 30);
        items[2] = new Song("Imagine", 180);
        PlayAll(items);
        Console.WriteLine("total seconds = " + TotalSeconds(items));
        Video v = new Video("Dogs", 45);
        IShareable s = v;
        Console.WriteLine(s.Share());
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
