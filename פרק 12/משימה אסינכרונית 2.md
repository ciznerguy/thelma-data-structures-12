## איפה עובדים

בסביבת הקוד של סטאקס: **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**. מוחקים את הקוד שנפתח, ומדביקים את השלד שבסעיף **השלד של התוכנית**.

## מבוא

ממשק יכול לרשת מממשק אחר, ולהוסיף לו פעולות. במשימה הזו תכתבו ממשק של דבר שיש לו ציון, ממשק יורש שמוסיף דירוג, ומחלקות לא קשורות שמממשות אותם. תכתבו גם אלגוריתם אחד, מציאת הציון הגבוה ביותר, שעובד על כולן.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: הממשק IScorable

כתבו ממשק `IScorable` עם שתי פעולות: `GetName` שמחזירה מחרוזת, ו-`GetScore` שמחזירה מספר שלם.

חתימה:

```csharp
interface IScorable
```

### שלב 2: המחלקה Student

כתבו מחלקה `Student` שמממשת את `IScorable`, עם תכונות פרטיות `name` ו-`grade`. הציון הוא הערך של `grade`.

חתימה:

```csharp
class Student : IScorable
public Student(string name, int grade)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Student("Dana", 90).GetName()` | `Dana` |
| `new Student("Dana", 90).GetScore()` | `90` |

### שלב 3: המחלקה Team

כתבו מחלקה `Team`, שאין לה קשר ל-`Student`, ומממשת גם היא את `IScorable`. יש לה תכונות פרטיות `name`, `wins` ו-`draws`. הציון שלה הוא 3 נקודות לכל ניצחון ונקודה אחת לכל תיקו.

חתימה:

```csharp
class Team : IScorable
public Team(string name, int wins, int draws)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Team("Reds", 5, 2).GetScore()` | `17` |
| `new Team("Reds", 5, 2).GetName()` | `Reds` |

### שלב 4: הציון הגבוה ביותר

כתבו בתוך `Program` פעולה סטטית שמקבלת מערך של `IScorable` ומחזירה את הפריט עם הציון הגבוה ביותר. אם יש כמה, את הראשון. הפעולה לא יודעת אם הפריט הוא תלמיד או קבוצה.

חתימה:

```csharp
static IScorable Best(IScorable[] items)
```

### שלב 5: ממשק יורש ושימוש בו

כתבו ממשק `IRankable` שיורש מ-`IScorable`, ומוסיף פעולה `GetRank` שמחזירה מספר שלם. כתבו מחלקה `Player` שמממשת אותו: תכונות פרטיות `name`, `score` ו-`rank`. כתבו בתוך `Program` פעולה סטטית `Describe(IRankable r)` שמחזירה מחרוזת בפורמט `#1 Gil (score 80)`: סולמית, הדירוג, רווח, השם, רווח, ובסוגריים המילה score ואחריה הציון.

חתימה:

```csharp
interface IRankable : IScorable
class Player : IRankable
static string Describe(IRankable r)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `Describe(new Player("Gil", 80, 1))` | `#1 Gil (score 80)` |

> **רמז:** מחלקה שמממשת ממשק יורש חייבת לממש את הפעולות של שני הממשקים.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        IScorable[] items = new IScorable[4];
        items[0] = new Student("Dana", 90);
        items[1] = new Team("Reds", 5, 2);
        items[2] = new Student("Avi", 75);
        items[3] = new Team("Blues", 6, 1);
        for (int i = 0; i < items.Length; i++)
        {
            Console.WriteLine(items[i].GetName() + ": " + items[i].GetScore());
        }
        IScorable best = Best(items);
        Console.WriteLine("best: " + best.GetName() + " with " + best.GetScore());
        Player p = new Player("Gil", 80, 1);
        Console.WriteLine(Describe(p));
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```

## הפלט הצפוי

בהרצה של פתרון נכון מתקבל בדיוק הפלט הזה:

```text

Reds: 17
Avi: 75
Blues: 19
best: Dana with 90
#1 Gil (score 80)
```
