# פרק 12: ממשקים

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **ממשקים**.

## בקצרה

- ממשק מגדיר התנהגות בלי מימוש. היחס הוא יכול ל.
- מחלקה שמממשת ממשק חייבת לממש את כל הפעולות שלו.
- מחלקה יורשת ממחלקה אחת, אבל יכולה לממש כמה ממשקים.
- משתנה או פרמטר מסוג ממשק מקבל עצם של כל מחלקה שמממשת אותו.
- ממשק יכול לרשת מממשק אחר.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_FirstInterface`: הממשק הראשון
2. `Example02_Contract`: ממשק כחוזה
3. `Example03_TwoInterfaces`: כמה ממשקים
4. `Example04_InterfaceVariable`: משתנה מסוג ממשק
5. `Example05_InterfaceParameter`: ממשק כפרמטר
6. `Example06_InterfaceInheritance`: ירושה בין ממשקים
7. `Example07_CanDo`: סוג של ויכול ל
8. `Example08_ShapesInterface`: צורות בעזרת ממשק
9. `Example09_Comparable`: ממשק להשוואה
10. `Example10_AbstractAndInterface`: מחלקה מופשטת וממשק יחד

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 12](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek12` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 12"
dotnet run
```
