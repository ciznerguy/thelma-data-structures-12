# פרק 2: רקורסיה

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **רקורסיה**.

## בקצרה

- פעולה רקורסיבית קוראת לעצמה. חייבים תנאי עצירה וקריאה רקורסיבית עם פרמטר קטן יותר.
- בלי תנאי עצירה הפעולה לא נגמרת, והתוכנית קורסת.
- הקריאות נערמות עד תנאי העצירה, והערכים חוזרים בסדר הפוך. כך עוקבים אחרי ריצה בעזרת טבלת מעקב.
- סוגי רקורסיה: רגילה, כפולה (פיבונאצ'י) והדדית.
- לרקורסיה יתרון בפשטות הפתרון, וחיסרון בצריכת זמן וזיכרון.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_Countdown`: ספירה לאחור, הרקורסיה הראשונה
2. `Example02_SumToN`: סכום המספרים מ-1 ועד מספר נתון, ומעקב אחרי הקריאות
3. `Example03_Factorial`: עצרת
4. `Example04_Power`: חזקה
5. `Example05_Fibonacci`: סדרת פיבונאצ'י, רקורסיה כפולה
6. `Example06_SumOfDigits`: סכום הספרות של מספר שלם
7. `Example07_ArraySum`: סכום איברי מערך
8. `Example08_ArrayMax`: הערך הגדול ביותר במערך
9. `Example09_EvenOdd`: רקורסיה הדדית
10. `Example10_PrintBinary`: הדפסת מספר בבסיס שתיים

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 2](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek02` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 02"
dotnet run
```
