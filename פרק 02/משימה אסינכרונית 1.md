# משימה אסינכרונית 1: רקורסיה ראשונה

**פרק 2: רקורסיה**

> **זמן מוערך: עד 90 דקות.** המשימה מוגשת בסטאקס, וכל הגשה מקבלת ציון.

## איפה עובדים

בסביבת הקוד של סטאקס: **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**. מוחקים את הקוד שנפתח, ומדביקים את השלד שבסעיף **השלד של התוכנית**.

## מבוא

פעולה רקורסיבית קוראת לעצמה, עם פרמטר קטן יותר, עד שמגיעים למקרה הפשוט ביותר: תנאי העצירה. במשימה הזו תכתבו כמה פעולות רקורסיביות פשוטות, ותעקבו אחרי ריצה של אחת מהן.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- בפעולות שנדרשות להיות רקורסיביות אסור להשתמש בלולאות.

## שלבי העבודה

### שלב 1: הדפסת כוכביות

הפעולה מדפיסה n כוכביות בשורה אחת, בעזרת `Console.Write`, בלי לעבור לשורה חדשה. מי שקורא לפעולה אחראי למעבר שורה. תנאי העצירה: n שווה 0.

חתימה:

```csharp
static void PrintStars(int n)
```

> **רמז:** הדפיסו כוכבית אחת, וקראו לפעולה עם n פחות 1.

### שלב 2: סכום טווח

הפעולה מחזירה את סכום כל המספרים השלמים מ-a ועד b, כולל. מניחים ש-a קטן או שווה ל-b. הרעיון: הסכום עד b שווה ל-b ועוד הסכום מ-a עד המספר שלפני b. תנאי העצירה: a שווה ל-b.

חתימה:

```csharp
static int SumRange(int a, int b)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `SumRange(3, 6)` | `18` |
| `SumRange(5, 5)` | `5` |
| `SumRange(1, 4)` | `10` |

> **רמז:** חשבו על SumRange(3, 6): 6 ועוד SumRange(3, 5).

### שלב 3: ספירת ספרות

הפעולה מחזירה כמה ספרות יש במספר שלם חיובי. חלוקה ב-10 בחלוקה שלמה מוחקת את הספרה האחרונה. תנאי העצירה: מספר קטן מ-10 מורכב מספרה אחת.

חתימה:

```csharp
static int CountDigits(int num)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `CountDigits(5072)` | `4` |
| `CountDigits(9)` | `1` |
| `CountDigits(100)` | `3` |

### שלב 4: כפל בעזרת חיבור

הפעולה מחזירה את המכפלה של a ו-b, בלי להשתמש באופרטור הכפל. מניחים ש-b גדול או שווה ל-0. הרעיון: a כפול b שווה ל-a ועוד a כפול b פחות 1. תנאי העצירה: b שווה 0.

חתימה:

```csharp
static int Multiply(int a, int b)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `Multiply(6, 4)` | `24` |
| `Multiply(5, 0)` | `0` |
| `Multiply(3, 1)` | `3` |

### שלב 5: ספירת מופעים במערך

הפעולה מחזירה כמה פעמים הערך value מופיע במערך, מהמקום index ועד סוף המערך. כדי לעבור על המערך ברקורסיה מעבירים בכל קריאה את המקום הבא. תנאי העצירה: המקום הגיע לאורך המערך.

חתימה:

```csharp
static int CountValue(int[] arr, int index, int value)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `CountValue(new int[] { 3, 7, 3 }, 0, 3)` | `2` |
| `CountValue(new int[] { 3, 7, 3 }, 1, 3)` | `1` |
| `CountValue(new int[] { 1, 2 }, 0, 5)` | `0` |

> **רמז:** אם האיבר הנוכחי שווה לערך, מוסיפים 1 לתוצאה של שאר המערך. אחרת התוצאה היא של שאר המערך בלבד.

### שלב 6: מעקב אחרי רקורסיה

הפעולה הבאה מדפיסה ערך לפני הקריאה הרקורסיבית וגם אחריה. לפני שמריצים, כתבו על דף טבלת מעקב: מה יודפס עבור n שווה 3? אחר כך כתבו את הפעולה והריצו, ובדקו אם צדקתם.

חתימה:

```csharp
static void Mystery(int n)
```

> **רמז:** הפעולה מדפיסה את n ורווח, קוראת לעצמה עם n פחות 1, ואז שוב מדפיסה את n ורווח. תנאי העצירה: n שווה 0.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Console.Write("Stars: ");
        PrintStars(5);
        Console.WriteLine();
        Console.WriteLine("SumRange(3,6) = " + SumRange(3, 6));
        Console.WriteLine("CountDigits(5072) = " + CountDigits(5072));
        Console.WriteLine("Multiply(6,4) = " + Multiply(6, 4));
        Console.WriteLine("Multiply(5,0) = " + Multiply(5, 0));
        int[] arr = new int[] { 3, 7, 3, 3, 9, 3 };
        Console.WriteLine("CountValue = " + CountValue(arr, 0, 3));
        Console.Write("Mystery: ");
        Mystery(3);
        Console.WriteLine();
    }

    // כאן כותבים את הפעולות של שלבי העבודה
}
```
