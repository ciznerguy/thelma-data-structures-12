## שלבי העבודה

### שלב 1: המחלק המשותף הגדול ביותר

הפעולה מחזירה את המחלק המשותף הגדול ביותר של שני מספרים חיוביים, לפי האלגוריתם של אוקלידס. אם b שווה 0, התוצאה היא a. אחרת המחלק של a ושל b שווה למחלק של b ושל שארית החלוקה של a ב-b. למשל עבור 48 ו-18: המחלק של 48 ו-18 שווה למחלק של 18 ו-12, ואחר כך 12 ו-6, ואחר כך 6 ו-0, והתוצאה היא 6.

חתימה:

```csharp
static int Gcd(int a, int b)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `Gcd(48, 18)` | `6` |
| `Gcd(17, 5)` | `1` |
| `Gcd(10, 0)` | `10` |

### שלב 2: היפוך מספר

הפעולה מחזירה את המספר num כשהספרות שלו בסדר הפוך. הפרמטר השני, acc, צובר את התוצאה בדרך. בכל קריאה מעבירים את הספרה האחרונה של num אל acc: ערך חדש של acc הוא acc כפול 10 ועוד הספרה האחרונה. ובקריאה הרקורסיבית num מאבד את הספרה האחרונה. תנאי העצירה: num שווה 0, והתוצאה היא acc. קוראים לפעולה תמיד עם acc שווה 0.

חתימה:

```csharp
static int ReverseNumber(int num, int acc)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `ReverseNumber(1234, 0)` | `4321` |
| `ReverseNumber(70, 0)` | `7` |
| `ReverseNumber(5, 0)` | `5` |

> **רמז:** עקבו אחרי ReverseNumber(123, 0): acc הוא 0, אחר כך 3, אחר כך 32, אחר כך 321.

### שלב 3: מספר בבסיס שתיים

הפעולה מחזירה מחרוזת עם הייצוג הבינארי של מספר שלם חיובי. אם המספר קטן מ-2, התוצאה היא המספר עצמו כמחרוזת. אחרת, התוצאה היא הייצוג הבינארי של num חלקי 2, ואחריו הספרה num מודולו 2. כדי להפוך מספר למחרוזת אפשר לשרשר אותו למחרוזת ריקה.

חתימה:

```csharp
static string ToBinary(int num)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `ToBinary(10)` | `1010` |
| `ToBinary(37)` | `100101` |
| `ToBinary(1)` | `1` |

### שלב 4: האם המערך ממוין

הפעולה בודקת אם איברי המערך ממוינים בסדר עולה, מהמקום index עד הסוף. אם המקום הנוכחי הוא האחרון או אחריו, התשובה היא אמת. אם האיבר הנוכחי גדול מהבא אחריו, התשובה היא שקר. אחרת, התשובה היא התשובה לגבי שאר המערך.

חתימה:

```csharp
static bool IsSorted(int[] arr, int index)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `IsSorted(new int[] { 1, 3, 5, 8 }, 0)` | `True` |
| `IsSorted(new int[] { 1, 4, 2, 9 }, 0)` | `False` |
| `IsSorted(new int[] { 7 }, 0)` | `True` |

### שלב 5: מגדלי האנוי

יש שלושה מוטות ומגדל של n דיסקיות. צריך להעביר את כל הדיסקיות מהמוט `from` אל המוט `to`, בעזרת המוט `via`, כשמעבירים דיסקית אחת בכל פעם ואסור להניח דיסקית גדולה על קטנה. הפעולה מדפיסה את כל ההעברות, שורה לכל העברה, בפורמט `Move disk 1 from 1 to 3`. הרעיון: מעבירים n פחות 1 דיסקיות אל המוט העזר, מעבירים את הדיסקית הגדולה אל היעד, ומעבירים את n פחות 1 הדיסקיות מהעזר ליעד. תנאי העצירה: אין דיסקיות. המספר של הדיסקית הוא n.

חתימה:

```csharp
static void Hanoi(int n, int from, int to, int via)
```

> **רמז:** הפעולה קוראת לעצמה פעמיים, והדפסה אחת ביניהן.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("Gcd(48,18) = " + Gcd(48, 18));
        Console.WriteLine("Gcd(17,5) = " + Gcd(17, 5));
        Console.WriteLine("Reverse = " + ReverseNumber(1234, 0));
        Console.WriteLine("Binary of 10 = " + ToBinary(10));
        Console.WriteLine("Binary of 37 = " + ToBinary(37));
        int[] a = new int[] { 1, 3, 5, 8 };
        int[] b = new int[] { 1, 4, 2, 9 };
        Console.WriteLine("IsSorted {1,3,5,8} = " + IsSorted(a, 0));
        Console.WriteLine("IsSorted {1,4,2,9} = " + IsSorted(b, 0));
        Console.WriteLine("Hanoi moves:");
        Hanoi(3, 1, 3, 2);
    }

    // כאן כותבים את הפעולות של שלבי העבודה
}
```

## אתגר רשות

כתבו את הפעולה `HanoiMoves(int n)`, שמחזירה כמה העברות נדרשות לפתרון מגדלי האנוי עם n דיסקיות, בלי להדפיס אותן. רמז: כדי להעביר n דיסקיות צריך להעביר n פחות 1, אחר כך דיסקית אחת, ואחר כך שוב n פחות 1.

| קריאה | תוצאה |
|---|---|
| `HanoiMoves(3)` | `7` |
| `HanoiMoves(5)` | `31` |
