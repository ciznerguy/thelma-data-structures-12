איך מריצים בסטאקס

אין צורך להתקין כלום. מי שרוצה לעבוד ב-Visual Studio 2022 או ב-.NET 8 יכול לפתוח את הפתרון ThelmaDataStructures12.sln.

  1. פותחים את סטאקס
    סביבת הקוד של סטאקס. לוחצים על סביבת קוד ← פרויקט חדש ← נותנים שם לפרויקט ← בוחרים בשפה C#.
  2. מנקים את הקובץ
    מוחקים את הקוד שמופיע בקובץ שנפתח. אם מתקבלות שגיאות של Java, הפרויקט נוצר בשפה לא נכונה, וצריך ליצור פרויקט חדש בשפת C#.
  3. מעתיקים ומדביקים
    בכרטיס של הפרק לוחצים על "העתק קוד" ומדביקים בקובץ. כל פרק הוא קובץ אחד שעומד בפני עצמו.
  4. מריצים
    לוחצים על הרצה (F9). ב-Main כל שורה מפעילה דוגמה, ואפשר לסמן שורות בהערה (//) כדי להריץ רק דוגמה מסוימת.

ב-Visual Studio או משורת הפקודה (לא חובה):

git clone https://github.com/ciznerguy/thelma-data-structures-12.git
cd "פרק 05"
dotnet run

הערות על הקוד

  • ההערות בקוד כתובות בעברית בלבד, והפלט של התוכניות באנגלית כדי שיוצג נכון בכל חלון הרצה.
  • הקוד תואם את תכנית הלימודים: בלי אופרטור תנאי מקוצר, בלי השמות מקוצרות, בלי switch, do-while, break, continue ו-try/catch.
  • בפרקים 3 עד 6 המחלקות של תכנית הלימודים (חוליה, תור, מחסנית, חוליה בינארית) כתובות בהמשך אותו קובץ, ובפרקים 7 עד 12 המחלקות כתובות בהמשך הקובץ. לכן מעתיקים קובץ אחד בלבד.
  • משימות אסינכרוניות מוגשות בסטאקס, וכל הגשה מקבלת ציון.
  • בכל פרק שנלמד יש מבחן תרגול של 15 שאלות, ללמידה בלבד: אין ציון שנשמר.
