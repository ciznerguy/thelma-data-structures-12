# פרק 7: מחלקות ועצמים

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **מחלקות ועצמים**.

## בקצרה

- מחלקה היא תבנית, ועצם הוא מופע שלה. לעצם יש תכונות ופעולות.
- הבנאי מאתחל את התכונות. התכונות פרטיות, והגישה אליהן דרך פעולות קבלה ועדכון.
- שאילתה מחזירה ערך ולא משנה את העצם. פקודה משנה את מצב העצם.
- מצב תקין הוא מצב שמקיים את הכללים של המחלקה.
- משתנה מסוג מחלקה מכיל הפניה לעצם. השמה מעתיקה את ההפניה ולא את העצם.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_FirstClass`: המחלקה הראשונה
2. `Example02_ManyObjects`: הרבה עצמים ממחלקה אחת
3. `Example03_Setters`: פעולות עדכון
4. `Example04_ToString`: המרה למחרוזת
5. `Example05_Methods`: פעולות שמחשבות
6. `Example06_ValidState`: מצב תקין
7. `Example07_Constructors`: כמה בנאים
8. `Example08_ValidInSetter`: בדיקה בפעולת העדכון
9. `Example09_References`: הפניות
10. `Example10_ObjectAsParameter`: עצם כפרמטר

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 7](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek07` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 07"
dotnet run
```
