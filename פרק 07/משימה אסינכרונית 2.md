## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: התכונות והבנאי

הגדירו את המחלקה `Wallet` עם תכונות פרטיות: `owner` מסוג מחרוזת ו-`balance` מסוג מספר שלם. כתבו בנאי שמקבל את שניהם.

חתימה:

```csharp
public Wallet(string owner, int balance)
```

### שלב 2: פעולות קבלה והמרה למחרוזת

כתבו פעולות קבלה לשם ולסכום. כתבו גם דריסה של ההמרה למחרוזת בפורמט `Dana: 100`.

חתימה:

```csharp
public string GetOwner()
public int GetBalance()
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Wallet("Dana", 100)` | `Dana: 100` |
| `new Wallet("Dana", 100).GetBalance()` | `100` |

### שלב 3: הוספת כסף

פעולה שמוסיפה לארנק סכום, רק אם הסכום חיובי. סכום שאינו חיובי אינו משנה דבר.

חתימה:

```csharp
public void Add(int amount)
```

### שלב 4: הוצאת כסף

פעולה שמוציאה מהארנק סכום. אם הסכום חיובי והוא לא גדול מהיתרה, מורידים אותו מהיתרה ומחזירים אמת. אחרת, היתרה לא משתנה ומחזירים שקר.

חתימה:

```csharp
public bool Spend(int amount)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Wallet("Dana", 100).Spend(40)` | `True` |
| `new Wallet("Dana", 100).Spend(500)` | `False` |
| `new Wallet("Dana", 100).Spend(-5)` | `False` |

### שלב 5: העברה בין ארנקים

כתבו, בתוך המחלקה `Program`, פעולה סטטית שמקבלת שני ארנקים וסכום. אם אפשר להוציא את הסכום מהארנק `from`, מוסיפים אותו לארנק `to` ומחזירים אמת. אחרת לא משנים דבר ומחזירים שקר. הפעולה משנה את העצמים עצמם, כי מועברות אליה הפניות.

חתימה:

```csharp
static bool Transfer(Wallet from, Wallet to, int amount)
```

> **רמז:** השתמשו בערך שמחזירה הפעולה Spend.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Wallet a = new Wallet("Dana", 100);
        Wallet b = new Wallet("Avi", 20);
        Console.WriteLine(a);
        Console.WriteLine(b);
        Console.WriteLine("transfer 30: " + Transfer(a, b, 30));
        Console.WriteLine("transfer 500: " + Transfer(a, b, 500));
        Console.WriteLine(a);
        Console.WriteLine(b);
        Wallet c = a;
        c.Add(1000);
        Console.WriteLine("a after c.Add: " + a);
        Console.WriteLine("a and c are the same object? " + (a == c));
        Wallet d = new Wallet("Dana", 1070);
        Console.WriteLine("a and d are the same object? " + (a == d));
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
