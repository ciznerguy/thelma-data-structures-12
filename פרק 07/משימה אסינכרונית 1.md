**פרק 7: מחלקות ועצמים**

> **זמן מוערך: עד 90 דקות.** המשימה מוגשת בסטאקס, וכל הגשה מקבלת ציון.

## איפה עובדים

בסביבת הקוד של סטאקס: **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**. מוחקים את הקוד שנפתח, ומדביקים את השלד שבסעיף **השלד של התוכנית**.

## מבוא

מחלקה היא תבנית שמגדירה אילו תכונות ופעולות יהיו לעצמים. במשימה הזו תכתבו מחלקה אחת שמתארת ספר: התכונות שלה פרטיות, הבנאי מאתחל אותן, ויש פעולות קבלה ועדכון. הפעולה שמעדכנת את מספר העמודים בודקת שהערך חוקי.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: התכונות והבנאי

הגדירו את המחלקה `Book` עם שתי תכונות פרטיות: `title` מסוג מחרוזת ו-`pages` מסוג מספר שלם. כתבו בנאי שמקבל שם ומספר עמודים ומציב אותם בתכונות.

חתימה:

```csharp
public Book(string title, int pages)
```

> **רמז:** בבנאי כותבים this.title = title; כדי להבדיל בין התכונה לבין הפרמטר.

### שלב 2: פעולות קבלה

כתבו פעולה שמחזירה את השם ופעולה שמחזירה את מספר העמודים.

חתימה:

```csharp
public string GetTitle()
public int GetPages()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Book("Dune", 412).GetTitle()` | `Dune` |
| `new Book("Dune", 412).GetPages()` | `412` |

### שלב 3: עדכון מספר העמודים

כתבו פעולת עדכון שמשנה את מספר העמודים רק אם הערך החדש גדול מ-0. אם הערך אינו חוקי, מספר העמודים נשאר כמו שהוא. כך הספר נשאר תמיד במצב תקין.

חתימה:

```csharp
public void SetPages(int pages)
```

### שלב 4: שאילתה: האם הספר ארוך

כתבו פעולה שמחזירה אמת אם בספר יותר מ-300 עמודים, ושקר אחרת.

חתימה:

```csharp
public bool IsLong()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Book("Dune", 412).IsLong()` | `True` |
| `new Book("Poems", 80).IsLong()` | `False` |
| `new Book("Edge", 300).IsLong()` | `False` |

### שלב 5: המרה למחרוזת

כתבו פעולה שדורסת את ההמרה למחרוזת, כך שהדפסת ספר תציג את השם ואת מספר העמודים בפורמט המדויק `Dune (412 pages)`.

חתימה:

```csharp
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Book("Dune", 412)` | `Dune (412 pages)` |

> **רמז:** המילה השמורה override מציינת שהפעולה מחליפה את הפעולה שהמחלקה ירשה.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Book a = new Book("Dune", 412);
        Book b = new Book("Poems", 80);
        Console.WriteLine(a);
        Console.WriteLine(b);
        Console.WriteLine("a is long? " + a.IsLong());
        Console.WriteLine("b is long? " + b.IsLong());
        b.SetPages(-5);
        Console.WriteLine("after invalid change: " + b);
        b.SetPages(320);
        Console.WriteLine("after valid change: " + b);
        Console.WriteLine("b is long? " + b.IsLong());
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
