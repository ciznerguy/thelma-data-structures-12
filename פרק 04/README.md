# פרק 4: מחסנית

- ⚠ **פרק זה לא נלמד השנה (תשפ"ז) בעקבות המיקוד. החומר מצורף לעיון בלבד.**

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **מחסנית**.

## בקצרה

- מחסנית פועלת לפי העיקרון האחרון נכנס ראשון יוצא.
- הפעולות: הכנסה לראש, הוצאה מהראש, הצצה בראש ובדיקה אם המחסנית ריקה.
- המחסנית גנרית, ולכן אפשר ליצור מחסנית של כל סוג ערכים.
- שימושים נפוצים: היפוך סדר, בדיקת סוגריים והמרה לבסיס שתיים.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_FirstStack`: מחסנית ראשונה
2. `Example02_TopAndIsEmpty`: ראש המחסנית ובדיקה אם המחסנית ריקה
3. `Example03_EmptyTheStack`: ריקון המחסנית
4. `Example04_StackOfStrings`: מחסנית של מחרוזות
5. `Example05_ReverseWord`: היפוך מילה
6. `Example06_CountAndSum`: ספירה וסכום
7. `Example07_CopyStack`: העתקת מחסנית בלי לאבד אותה
8. `Example08_Max`: הערך הגדול ביותר במחסנית
9. `Example09_Brackets`: בדיקת סוגריים תקינים
10. `Example10_DecimalToBinary`: המרה למספר בינארי

המחלקות של תכנית הלימודים, `Node<T>` ו-`Stack<T>`, נמצאות בסוף הקובץ, כדי שאפשר יהיה להעתיק קובץ אחד ולהריץ אותו.

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 4](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek04` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 04"
dotnet run
```
