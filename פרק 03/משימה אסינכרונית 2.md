## שלבי העבודה

### שלב 1: בניית תור

הפעולה מקבלת מערך של מספרים, ומחזירה תור שבו המספרים לפי הסדר שבמערך: האיבר הראשון במערך הוא ראש התור.

חתימה:

```csharp
static Queue<int> BuildQueue(int[] values)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `BuildQueue(new int[] { 4, 8, 2 })` | `QueueHead[4,8,2]` |
| `BuildQueue(new int[] { })` | `[]` |

> **רמז:** צרו תור ריק, ועברו על המערך בלולאה. אחרי הפעולה Insert האיבר נכנס לסוף התור.

### שלב 2: העתקת תור

הפעולה מחזירה תור חדש עם אותם איברים באותו סדר. אחרי הפעולה התור המקורי q חייב להישאר עם אותם איברים באותו סדר, כמו לפני הפעולה. כדי להחזיר את האיברים מוציאים אותם לתור עזר, ואז מכניסים אותם בחזרה.

חתימה:

```csharp
static Queue<int> CopyQueue(Queue<int> q)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `CopyQueue(BuildQueue(new int[] { 1, 2, 3 }))` | `QueueHead[1,2,3]` |

> **רמז:** כל איבר שמוציאים מ-q מכניסים גם לתור החדש וגם לתור העזר. בסוף מחזירים את תור העזר ל-q.

### שלב 3: הסרת שליליים

הפעולה מחזירה תור חדש שמכיל רק את האיברים הלא שליליים (0 או גדולים), לפי סדרם בתור המקורי. אחרי הפעולה מותר לתור המקורי להיות ריק.

חתימה:

```csharp
static Queue<int> RemoveNegatives(Queue<int> q)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `RemoveNegatives(BuildQueue(new int[] { 4, -1, 7, -5, 0 }))` | `QueueHead[4,7,0]` |

### שלב 4: מיזוג תורים ממוינים

שני התורים a ו-b ממוינים מהקטן לגדול. הפעולה מחזירה תור חדש ממוין עם כל האיברים משניהם. בכל צעד משווים את ראשי שני התורים ומוציאים את הקטן יותר. כשאחד התורים נגמר מעבירים את כל מה שנשאר בתור השני. אחרי הפעולה מותר לתורים a ו-b להיות ריקים.

חתימה:

```csharp
static Queue<int> MergeSorted(Queue<int> a, Queue<int> b)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `MergeSorted(BuildQueue(new int[] { 1, 4, 9 }), BuildQueue(new int[] { 2, 3, 10, 12 }))` | `QueueHead[1,2,3,4,9,10,12]` |

> **רמז:** שימו לב שלפני שמשווים את הראשים צריך לוודא ששני התורים אינם ריקים.

### שלב 5: סיבוב התור

הפעולה מעבירה את k האיברים הראשונים של התור לסופו, לפי הסדר. התור q משתנה, ולכן הפעולה אינה מחזירה ערך. מניחים ש-k קטן או שווה למספר האיברים בתור. למשל התור 1, 2, 3, 4, 5 עם k שווה 2 הופך לתור 3, 4, 5, 1, 2.

חתימה:

```csharp
static void Rotate(Queue<int> q, int k)
```

> **רמז:** חזרו k פעמים: הוציאו איבר מהראש והכניסו אותו לסוף.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Queue<int> q = BuildQueue(new int[] { 1, 2, 3, 4, 5 });
        Queue<int> copy = CopyQueue(q);
        Console.WriteLine("original: " + q);
        Console.WriteLine("copy: " + copy);
        Queue<int> mixed = BuildQueue(new int[] { 4, -1, 7, -5, 0, 9 });
        Console.WriteLine("no negatives: " + RemoveNegatives(mixed));
        Queue<int> a = BuildQueue(new int[] { 1, 4, 9 });
        Queue<int> b = BuildQueue(new int[] { 2, 3, 10, 12 });
        Console.WriteLine("merged: " + MergeSorted(a, b));
        Rotate(q, 2);
        Console.WriteLine("rotated: " + q);
    }

    // כאן כותבים את הפעולות של שלבי העבודה
}
```

הפעולות והמחלקות הבאות מוכנות, ולכן מעתיקים אותן כמו שהן מסוף הקובץ `Program.cs` של הפרק, מתחת לשלד: **`Node`, `Queue`**.

## הפלט הצפוי

בהרצה של פתרון נכון מתקבל בדיוק הפלט הזה:

```text

```

## אתגר רשות

חיילים עומדים בתור ומקבלים מספרים מ-1 עד n. בכל סבב מעבירים את k פחות 1 החיילים הראשונים לסוף התור, ואת החייל ה-k מוציאים מהמשחק. כך ממשיכים עד שנשאר חייל אחד. כתבו את הפעולה `LastStanding(int n, int k)` שמחזירה את המספר של החייל שנשאר.

| קריאה | תוצאה |
|---|---|
| `LastStanding(5, 2)` | `3` |
| `LastStanding(7, 3)` | `4` |
