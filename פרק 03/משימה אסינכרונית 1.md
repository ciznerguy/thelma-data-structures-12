**פרק 3: תור**

## איפה עובדים

בסביבת הקוד של סטאקס: **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**. מוחקים את הקוד שנפתח, ומדביקים את השלד שבסעיף **השלד של התוכנית**.

## מבוא

תור פועל לפי העיקרון הראשון נכנס ראשון יוצא. במשימה הזו תכתבו פעולות שעוברות על תור ומחשבות עליו, כמו ספירה, סכום וחיפוש. בכל הפעולות שבמשימה מותר לרוקן את התור תוך כדי העבודה.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- עובדים עם `Queue<T>` רק דרך פעולות הממשק שלו: `Insert`, `Remove`, `Head`, `IsEmpty`. אין לגשת לחוליות שבתוכו.

## שלבי העבודה

### שלב 1: בניית תור

הפעולה מקבלת מערך של מספרים, ומחזירה תור שבו המספרים לפי הסדר שבמערך: האיבר הראשון במערך הוא ראש התור.

חתימה:

```csharp
static Queue<int> BuildQueue(int[] values)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `BuildQueue(new int[] { 4, 8, 2 })` | `QueueHead[4,8,2]` |
| `BuildQueue(new int[] { })` | `[]` |

> **רמז:** צרו תור ריק, ועברו על המערך בלולאה. אחרי הפעולה Insert האיבר נכנס לסוף התור.

### שלב 2: ספירת איברים

הפעולה מחזירה כמה איברים יש בתור. אחרי הפעולה התור ריק, וזה בסדר.

חתימה:

```csharp
static int CountItems(Queue<int> q)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `CountItems(BuildQueue(new int[] { 4, 8, 2 }))` | `3` |
| `CountItems(BuildQueue(new int[] { }))` | `0` |

> **רמז:** מוציאים איבר בכל סיבוב, כל עוד התור אינו ריק.

### שלב 3: סכום האיברים

הפעולה מחזירה את סכום האיברים שבתור.

חתימה:

```csharp
static int SumItems(Queue<int> q)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `SumItems(BuildQueue(new int[] { 4, 8, 2 }))` | `14` |
| `SumItems(BuildQueue(new int[] { }))` | `0` |

### שלב 4: חיפוש ערך

הפעולה מחזירה אמת אם הערך x נמצא בתור, ושקר אם לא.

חתימה:

```csharp
static bool ContainsValue(Queue<int> q, int x)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `ContainsValue(BuildQueue(new int[] { 4, 8, 2 }), 8)` | `True` |
| `ContainsValue(BuildQueue(new int[] { 4, 8, 2 }), 5)` | `False` |

> **רמז:** גם אחרי שמצאתם, התור יכול להישאר עם איברים. זה בסדר.

### שלב 5: הערך הגדול ביותר

הפעולה מחזירה את הערך הגדול ביותר בתור. מניחים שהתור אינו ריק. התחילו מהאיבר הראשון.

חתימה:

```csharp
static int MaxItem(Queue<int> q)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `MaxItem(BuildQueue(new int[] { 4, 8, 2 }))` | `8` |
| `MaxItem(BuildQueue(new int[] { 7 }))` | `7` |

### שלב 6: ספירת זוגיים

הפעולה מחזירה כמה מהאיברים שבתור הם מספרים זוגיים.

חתימה:

```csharp
static int CountEven(Queue<int> q)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `CountEven(BuildQueue(new int[] { 4, 7, 2, 9, 6 }))` | `3` |
| `CountEven(BuildQueue(new int[] { 1, 3 }))` | `0` |

> **רמז:** מספר הוא זוגי אם השארית של חלוקתו ב-2 היא 0.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        int[] values = new int[] { 5, 8, 3, 12, 7 };
        Console.WriteLine("queue: " + BuildQueue(values));
        Console.WriteLine("count = " + CountItems(BuildQueue(values)));
        Console.WriteLine("sum = " + SumItems(BuildQueue(values)));
        Console.WriteLine("contains 12? " + ContainsValue(BuildQueue(values), 12));
        Console.WriteLine("contains 4? " + ContainsValue(BuildQueue(values), 4));
        Console.WriteLine("max = " + MaxItem(BuildQueue(values)));
        Console.WriteLine("even count = " + CountEven(BuildQueue(values)));
    }

    // כאן כותבים את הפעולות של שלבי העבודה
}
```

הפעולות והמחלקות הבאות מוכנות, ולכן מעתיקים אותן כמו שהן מסוף הקובץ `Program.cs` של הפרק, מתחת לשלד: **`Node`, `Queue`**.
