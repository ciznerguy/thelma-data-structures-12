# פרק 3: תור

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **תור**.

## בקצרה

- תור פועל לפי העיקרון הראשון נכנס ראשון יוצא.
- הפעולות: הכנסה לסוף התור, הוצאה מההתחלה, הצצה בראש התור ובדיקה אם התור ריק.
- התור גנרי, ולכן אפשר ליצור תור של כל סוג ערכים.
- כדי לעבור על תור ולא לאבד אותו משתמשים בתור עזר.
- תור מתאים לבעיות המתנה והעברה לפי סדר הגעה.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_FirstQueue`: תור ראשון
2. `Example02_HeadAndIsEmpty`: ראש התור ובדיקה אם התור ריק
3. `Example03_EmptyTheQueue`: ריקון התור
4. `Example04_QueueOfStrings`: תור של מחרוזות
5. `Example05_CountAndSum`: ספירה וסכום
6. `Example06_Max`: הערך הגדול ביותר בתור
7. `Example07_CopyQueue`: העתקת תור בלי לאבד אותו
8. `Example08_FilterQueue`: סינון תור
9. `Example09_MergeQueues`: מיזוג שני תורים ממוינים
10. `Example10_SupermarketLine`: תור בסופרמרקט

המחלקות של תכנית הלימודים, `Node<T>` ו-`Queue<T>`, נמצאות בסוף הקובץ, כדי שאפשר יהיה להעתיק קובץ אחד ולהריץ אותו.

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 3](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek03` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 03"
dotnet run
```
