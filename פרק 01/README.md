# פרק 1: יעילות

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **יעילות**.

## בקצרה

- יעילות נמדדת בספירת צעדים, לא בשניות, כי שניות תלויות במחשב.
- פעולה שמספר הצעדים שלה לא תלוי בגודל הקלט היא פעולה בצעדים קבועים.
- יש מקרה טוב, מקרה רע ומקרה ממוצע. למשל בחיפוש סדרתי.
- לולאה בתוך לולאה מכפילה את מספר הצעדים. לולאה שהמשתנה בה מוכפל היא מהירה בהרבה.
- חיפוש בינארי במערך ממוין יעיל בהרבה מחיפוש סדרתי.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_CountSteps`: ספירת צעדים
2. `Example02_ConstantSteps`: מספר צעדים קבוע
3. `Example03_LinearSearch`: חיפוש סדרתי, המקרה הטוב והמקרה הרע
4. `Example04_FindMax`: מציאת הערך הגדול ביותר
5. `Example05_NestedLoops`: לולאה בתוך לולאה
6. `Example06_SumByFormula`: שני פתרונות לאותה בעיה
7. `Example07_DoublingLoop`: לולאה שהמשתנה בה מוכפל
8. `Example08_BinarySearch`: חיפוש בינארי במערך ממוין
9. `Example09_ComparePrograms`: השוואה בין שתי תוכניות
10. `Example10_GrowthTable`: טבלת גידול

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 1](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek01` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 01"
dotnet run
```
