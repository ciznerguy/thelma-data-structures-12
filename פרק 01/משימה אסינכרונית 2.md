## איפה עובדים

בסביבת הקוד של סטאקס: **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**. מוחקים את הקוד שנפתח, ומדביקים את השלד שבסעיף **השלד של התוכנית**.

## מבוא

לאותה בעיה יש לפעמים כמה פתרונות, ומספר הצעדים שלהם גדל בקצבים שונים. במשימה הזו תספרו צעדים בכמה דפוסים של לולאות, ותדפיסו טבלה שמראה איך כל אחד מהם גדל כשגודל הקלט גדל.

## שלבי העבודה

### שלב 1: לולאה פשוטה

הפעולה מריצה לולאה שעוברת על המספרים מ-1 עד n, וסופרת כמה סיבובים בוצעו. היא מחזירה את הספירה.

חתימה:

```csharp
static int SimpleSteps(int n)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `SimpleSteps(4)` | `4` |
| `SimpleSteps(25)` | `25` |

> **רמז:** זו הפעולה הפשוטה ביותר במשימה. התוצאה שלה גדלה כמו הקלט.

### שלב 2: חצייה חוזרת

הפעולה מתחילה מהמספר n, ובכל סיבוב מחלקת אותו ב-2 בחלוקה שלמה, כל עוד הוא גדול מ-1. היא מחזירה כמה סיבובים בוצעו.

חתימה:

```csharp
static int HalvingSteps(int n)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `HalvingSteps(16)` | `4` |
| `HalvingSteps(100)` | `6` |
| `HalvingSteps(1)` | `0` |

> **רמז:** שימו לב: ההפך מהכפלה. המספר קטן מהר, ולכן הלולאה קצרה.

### שלב 3: משולש

הפעולה מריצה לולאה חיצונית שמשתנה הבקרה שלה i עובר מ-1 עד n, ובתוכה לולאה פנימית שמשתנה הבקרה שלה j עובר מ-1 עד i. היא סופרת כמה פעמים בוצע גוף הלולאה הפנימית.

חתימה:

```csharp
static int TriangleSteps(int n)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `TriangleSteps(4)` | `10` |
| `TriangleSteps(10)` | `55` |

> **רמז:** עבור n = 4 הלולאה הפנימית רצה 1, 2, 3 ו-4 פעמים.

### שלב 4: זוגות

הפעולה סופרת כמה זוגות שונים של מקומות אפשר ליצור במערך באורך n. משתנה הבקרה i עובר מ-0 עד n פחות 1, והמשתנה j מתחיל מ-i ועוד 1 ועובר עד n פחות 1. כל סיבוב של הלולאה הפנימית הוא זוג אחד.

חתימה:

```csharp
static int PairsSteps(int n)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `PairsSteps(4)` | `6` |
| `PairsSteps(10)` | `45` |

> **רמז:** כל זוג נספר פעם אחת. הזוג (0,1) והזוג (1,0) נחשבים לזוג אחד.

### שלב 5: טבלת השוואה

הפעולה מדפיסה טבלה. לכל n מהרשימה 4, 8, 16, 32 היא מדפיסה שורה אחת בפורמט המדויק שבפלט הצפוי, עם התוצאה של ארבע הפעולות הקודמות. אחרי הטבלה, כתבו הערה בעברית: איזה דפוס גדל הכי מהר, ואיזה הכי לאט.

חתימה:

```csharp
static void PrintTable()
```

> **רמז:** השתמשו בלולאה שמכפילה את n פי 2 בכל סיבוב, והדפיסו כל שורה בעזרת שרשור מחרוזות.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        PrintTable();
    }

    // כאן כותבים את הפעולות של שלבי העבודה
}
```
