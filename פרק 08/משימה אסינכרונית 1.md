## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: המחלקה Point

כתבו מחלקה `Point` עם שתי תכונות פרטיות `x` ו-`y` מסוג מספר שלם, בנאי שמקבל את שתיהן, פעולות קבלה `GetX`, `GetY`, פעולת עדכון `SetX`, ודריסה של ההמרה למחרוזת בפורמט `(3,4)`.

חתימה:

```csharp
public Point(int x, int y)
public int GetX()
public int GetY()
public void SetX(int x)
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Point(3, 4)` | `(3,4)` |

### שלב 2: המחלקה Rectangle: תכונות ובנאי

כתבו מחלקה `Rectangle` עם שלוש תכונות פרטיות: `topLeft` מסוג `Point`, `width` ו-`height` מסוג מספר שלם. הבנאי מקבל נקודה, רוחב וגובה.

חתימה:

```csharp
public Rectangle(Point topLeft, int width, int height)
```

### שלב 3: העמסת בנאי

כתבו בנאי נוסף באותה מחלקה, שמקבל ארבעה מספרים: x, y, רוחב וגובה, ויוצר בעצמו את הנקודה.

חתימה:

```csharp
public Rectangle(int x, int y, int width, int height)
```

> **רמז:** אפשר לאתחל את התכונה topLeft בעזרת new Point(x, y).

### שלב 4: שטח והמרה למחרוזת

כתבו פעולה שמחזירה את השטח, ודריסה של ההמרה למחרוזת בפורמט `rectangle at (1,2) size 4x3`.

חתימה:

```csharp
public int Area()
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Rectangle(1, 2, 4, 3).Area()` | `12` |
| `new Rectangle(1, 2, 4, 3)` | `rectangle at (1,2) size 4x3` |

### שלב 5: האם נקודה בתוך המלבן

הפעולה מחזירה אמת אם הנקודה נמצאת בתוך המלבן או על שפתו. ציר ה-x גדל ימינה וציר ה-y גדל כלפי מטה, ולכן הפינה השמאלית העליונה היא (x, y) והפינה הימנית התחתונה היא (x ועוד רוחב, y ועוד גובה).

חתימה:

```csharp
public bool Contains(Point p)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Rectangle(1, 2, 4, 3).Contains(new Point(3, 3))` | `True` |
| `new Rectangle(1, 2, 4, 3).Contains(new Point(5, 5))` | `True` |
| `new Rectangle(1, 2, 4, 3).Contains(new Point(6, 3))` | `False` |

### שלב 6: בנאי מעתיק

כתבו בנאי שמקבל מלבן אחר ויוצר מלבן חדש עם אותם ערכים. הנקודה של המלבן החדש חייבת להיות עצם חדש, כדי ששינוי בנקודה של אחד המלבנים לא ישפיע על האחר. לשם כך הוסיפו למלבן פעולה `GetTopLeft` שמחזירה את הנקודה.

חתימה:

```csharp
public Rectangle(Rectangle other)
public Point GetTopLeft()
```

> **רמז:** צרו נקודה חדשה עם אותם x ו-y של הנקודה של המלבן המקורי.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Rectangle r = new Rectangle(new Point(1, 2), 4, 3);
        Console.WriteLine(r);
        Console.WriteLine("area = " + r.Area());
        Console.WriteLine("contains (3,3)? " + r.Contains(new Point(3, 3)));
        Console.WriteLine("contains (6,3)? " + r.Contains(new Point(6, 3)));
        Rectangle s = new Rectangle(0, 0, 10, 10);
        Console.WriteLine(s);
        Rectangle copy = new Rectangle(r);
        r.GetTopLeft().SetX(100);
        Console.WriteLine("original: " + r);
        Console.WriteLine("copy: " + copy);
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
