## מבוא

במשימה הזו תכתבו מחלקה שמכילה מערך של עצמים. המחלקה `Course` שומרת תלמידים במערך בגודל קבוע, ומחשבת עליהם נתונים. אחת הפעולות מחזירה עצם, ובמקרה שאין עצם מתאים היא מחזירה ריק.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: המחלקה Student

כתבו מחלקה `Student` עם תכונות פרטיות `name` (מחרוזת) ו-`grade` (מספר שלם), בנאי שמקבל את שתיהן, פעולות קבלה `GetName` ו-`GetGrade`, ודריסה של ההמרה למחרוזת בפורמט `Dana: 90`.

חתימה:

```csharp
public Student(string name, int grade)
public string GetName()
public int GetGrade()
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Student("Dana", 90)` | `Dana: 90` |

### שלב 2: המחלקה Course: תכונות ובנאי

כתבו מחלקה `Course` עם שתי תכונות פרטיות: מערך `students` של עצמים מסוג `Student`, ומספר שלם `count` שאומר כמה תלמידים נמצאים בפועל במערך. הבנאי מקבל את הגודל המקסימלי של הכיתה, יוצר את המערך, ומאתחל את `count` ל-0. כתבו גם פעולה `GetCount` שמחזירה את `count`.

חתימה:

```csharp
public Course(int capacity)
public int GetCount()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Course(5).GetCount()` | `0` |

> **רמז:** יצירת המערך יוצרת רק תאים ריקים. את העצמים עצמם מכניסים בהמשך.

### שלב 3: הוספת תלמיד

הפעולה מוסיפה את התלמיד למקום הפנוי הראשון במערך ומגדילה את `count`. אם הכיתה מלאה, היא לא מוסיפה ומחזירה שקר. אחרת מחזירה אמת.

חתימה:

```csharp
public bool AddStudent(Student s)
```

> **רמז:** count הוא גם מספר התלמידים וגם המקום הפנוי הבא.

### שלב 4: ממוצע

הפעולה מחזירה את ממוצע הציונים של התלמידים שנמצאים בכיתה, כמספר עשרוני. אם אין תלמידים, מחזירה 0. כדי לחשב חלוקה עשרונית כותבים `(double)sum / count`.

חתימה:

```csharp
public double Average()
```

### שלב 5: התלמיד הטוב ביותר ומעל גבול

הפעולה `Best` מחזירה את התלמיד עם הציון הגבוה ביותר, או ריק אם אין תלמידים. הפעולה `CountAbove` מחזירה כמה תלמידים קיבלו ציון גבוה מ-`limit`, ממש.

חתימה:

```csharp
public Student Best()
public int CountAbove(int limit)
```

> **רמז:** במערך של עצמים עוברים רק על המקומות מ-0 עד count פחות 1.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Course c = new Course(4);
        Console.WriteLine("average of empty course = " + c.Average());
        Console.WriteLine("best of empty course is null? " + (c.Best() == null));
        Console.WriteLine("add Dana: " + c.AddStudent(new Student("Dana", 90)));
        Console.WriteLine("add Avi: " + c.AddStudent(new Student("Avi", 75)));
        Console.WriteLine("add Noa: " + c.AddStudent(new Student("Noa", 60)));
        Console.WriteLine("add Ron: " + c.AddStudent(new Student("Ron", 85)));
        Console.WriteLine("add Gil: " + c.AddStudent(new Student("Gil", 100)));
        Console.WriteLine("count = " + c.GetCount());
        Console.WriteLine("average = " + c.Average());
        Console.WriteLine("best = " + c.Best());
        Console.WriteLine("above 80: " + c.CountAbove(80));
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
