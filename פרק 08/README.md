# פרק 8: הכלת עצמים

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **הכלת עצמים**.

## בקצרה

- תכונה של מחלקה יכולה להיות עצם ממחלקה אחרת, או מערך של עצמים.
- מערך של עצמים מתחיל ריק, וצריך ליצור כל עצם בנפרד.
- העמסה: כמה בנאים או פעולות עם אותו שם ופרמטרים שונים.
- בנאי מעתיק יוצר עצם חדש עם אותם ערכים. העתקה עמוקה יוצרת גם עצמים פנימיים חדשים.
- פעולה יכולה להחזיר עצם, או ערך ריק אם לא נמצא עצם מתאים.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_ObjectInsideObject`: עצם בתוך עצם
2. `Example02_Circle`: עיגול עם מרכז
3. `Example03_Line`: קטע המורכב משתי נקודות
4. `Example04_ArrayOfObjects`: מערך של עצמים
5. `Example05_ClassWithArray`: מחלקה שמכילה מערך של עצמים
6. `Example06_SearchInArray`: חיפוש במערך של עצמים
7. `Example07_Overloading`: העמסה
8. `Example08_CopyConstructor`: בנאי מעתיק
9. `Example09_ShallowAndDeep`: העתקה רדודה והעתקה עמוקה
10. `Example10_ReturnObject`: פעולה שמחזירה עצם

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 8](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek08` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 08"
dotnet run
```
