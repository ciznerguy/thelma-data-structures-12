# פרק 9: הורשה

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **הורשה**.

## בקצרה

- מחלקה יורשת מקבלת את התכונות והפעולות של מחלקת האב. היחס הוא סוג של.
- הבנאי של המחלקה היורשת פונה לבנאי של האב.
- דריסה מגדירה מחדש פעולה של האב. אפשר להשתמש גם בגרסה של האב.
- תכונה מוגנת נגישה גם למחלקות יורשות. תכונה פרטית אינה נגישה להן.
- כל המחלקות יורשות מהמחלקה הראשונה, שממנה מקבלות את ההמרה למחרוזת.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_FirstInheritance`: ההורשה הראשונה
2. `Example02_BaseConstructor`: בנאי של מחלקת האב
3. `Example03_NewMembers`: חברים חדשים במחלקה היורשת
4. `Example04_Override`: דריסת פעולה
5. `Example05_CallBase`: קריאה לפעולה של מחלקת האב
6. `Example06_ToStringInherited`: המרה למחרוזת בהורשה
7. `Example07_ThreeLevels`: שלוש רמות של הורשה
8. `Example08_Protected`: הרשאת גישה מוגנת
9. `Example09_IsA`: היחס הוא סוג של
10. `Example10_Employees`: עובדים ומנהלים

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 9](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek09` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 09"
dotnet run
```
