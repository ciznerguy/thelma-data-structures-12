## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: מחלקת האב Vehicle

כתבו מחלקה `Vehicle` עם תכונות פרטיות `brand` (מחרוזת) ו-`year` (מספר שלם), בנאי שמקבל את שתיהן, פעולות קבלה `GetBrand` ו-`GetYear`, ודריסה של ההמרה למחרוזת בפורמט `Mazda (2018)`.

חתימה:

```csharp
public Vehicle(string brand, int year)
public string GetBrand()
public int GetYear()
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Vehicle("Mazda", 2018)` | `Mazda (2018)` |

### שלב 2: פעולה שתירש

הוסיפו ל-`Vehicle` פעולה שמחזירה את גיל הרכב בשנה הנתונה.

חתימה:

```csharp
public int Age(int currentYear)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Vehicle("Mazda", 2018).Age(2025)` | `7` |

### שלב 3: המחלקה Car

כתבו מחלקה `Car` שיורשת מ-`Vehicle`. נוסף לתכונות שהיא יורשת, יש לה תכונה פרטית `doors` (מספר שלם). הבנאי מקבל מותג, שנה ומספר דלתות, ומעביר את המותג והשנה לבנאי של מחלקת האב. הוסיפו פעולת קבלה `GetDoors`.

חתימה:

```csharp
class Car : Vehicle
public Car(string brand, int year, int doors) : base(brand, year)
public int GetDoors()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Car("Mazda", 2018, 4).GetBrand()` | `Mazda` |
| `new Car("Mazda", 2018, 4).Age(2025)` | `7` |

> **רמז:** פעולות GetBrand ו-Age אינן כתובות ב-Car, והן עובדות כי Car ירשה אותן.

### שלב 4: דריסת ההמרה למחרוזת ב-Car

דרסו את ההמרה למחרוזת, כך שתציג את התיאור של מחלקת האב ואחריו פסיק, רווח ומספר הדלתות בפורמט `Mazda (2018), 4 doors`. השתמשו בפעולה של מחלקת האב בעזרת `base.ToString()`.

חתימה:

```csharp
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Car("Mazda", 2018, 4)` | `Mazda (2018), 4 doors` |

### שלב 5: המחלקה Motorcycle

כתבו מחלקה `Motorcycle` שיורשת מ-`Vehicle`, עם תכונה פרטית `sidecar` מסוג בוליאני (האם יש סוויד). הבנאי מקבל מותג, שנה וערך בוליאני. ההמרה למחרוזת מציגה את התיאור של מחלקת האב ואחריו פסיק ורווח, ואז `with sidecar` או `no sidecar`. אסור להשתמש באופרטור התנאי המקוצר.

חתימה:

```csharp
class Motorcycle : Vehicle
public Motorcycle(string brand, int year, bool sidecar) : base(brand, year)
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Motorcycle("Honda", 2010, true)` | `Honda (2010), with sidecar` |
| `new Motorcycle("Honda", 2010, false)` | `Honda (2010), no sidecar` |

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Vehicle v = new Vehicle("Toyota", 2015);
        Car c = new Car("Mazda", 2018, 4);
        Motorcycle m = new Motorcycle("Honda", 2010, true);
        Console.WriteLine(v);
        Console.WriteLine(c);
        Console.WriteLine(m);
        Console.WriteLine("car doors = " + c.GetDoors());
        Console.WriteLine("car age = " + c.Age(2025));
        Console.WriteLine("motorcycle age = " + m.Age(2025));
        Console.WriteLine("car brand = " + c.GetBrand());
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
