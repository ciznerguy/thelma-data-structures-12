## מבוא

מחלקה יורשת יכולה לשנות את ההתנהגות של פעולה שירשה, בעזרת דריסה. במשימה הזו תכתבו חשבון בנק רגיל, חשבון חיסכון עם ריבית, וחשבון עובר ושב שמאפשר משיכת יתר. תתרגלו גם את ההרשאה המוגנת.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.
- כדי שמחלקה יורשת תוכל לשנות את היתרה, התכונה `balance` ב-`Account` תוגדר בהרשאה `protected`. זה היוצא מן הכלל היחיד לכלל התכונות הפרטיות במשימה.

## שלבי העבודה

### שלב 1: מחלקת האב Account

כתבו מחלקה `Account` עם תכונה מוגנת `balance` (מספר שלם) ובנאי שמקבל את היתרה ההתחלתית. הוסיפו: פעולת קבלה `GetBalance`, פעולה `Deposit` שמוסיפה סכום רק אם הוא חיובי, ופעולה `Withdraw` שמוציאה סכום רק אם הוא חיובי ולא גדול מהיתרה, ומחזירה אמת אם הצליחה ושקר אם לא. הפעולה `Withdraw` חייבת להיות מסומנת במילה השמורה שמאפשרת דריסה, `virtual`. דרסו את ההמרה למחרוזת בפורמט `balance: 100`.

חתימה:

```csharp
protected int balance;
public Account(int balance)
public int GetBalance()
public void Deposit(int amount)
public virtual bool Withdraw(int amount)
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Account(100)` | `balance: 100` |
| `new Account(100).Withdraw(30)` | `True` |
| `new Account(100).Withdraw(300)` | `False` |

### שלב 2: חשבון חיסכון

כתבו מחלקה `SavingsAccount` שיורשת מ-`Account`, עם תכונה פרטית `rate` (אחוז ריבית, מספר שלם). הבנאי מקבל יתרה ואחוז ריבית. הפעולה `AddInterest` מוסיפה ליתרה את הריבית: היתרה כפול האחוז, בחלוקה שלמה ב-100. ההמרה למחרוזת מציגה את התיאור של מחלקת האב ואחריו `, rate 5%`.

חתימה:

```csharp
class SavingsAccount : Account
public SavingsAccount(int balance, int rate) : base(balance)
public void AddInterest()
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new SavingsAccount(200, 5)` | `balance: 200, rate 5%` |

### שלב 3: חשבון עובר ושב

כתבו מחלקה `CheckingAccount` שיורשת מ-`Account`, עם תכונה פרטית `overdraft` (מגבלת משיכת יתר). הפעולה `Withdraw` נדרסת: מותר למשוך סכום חיובי כל עוד היתרה אחרי המשיכה לא יורדת מתחת למינוס `overdraft`. אם המשיכה הצליחה, מחזירים אמת, אחרת שקר ובלי שינוי. ההמרה למחרוזת מציגה את התיאור של מחלקת האב ואחריו `, overdraft 500`.

חתימה:

```csharp
class CheckingAccount : Account
public CheckingAccount(int balance, int overdraft) : base(balance)
public override bool Withdraw(int amount)
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new CheckingAccount(100, 500).Withdraw(400)` | `True` |
| `new CheckingAccount(100, 500).Withdraw(700)` | `False` |
| `new CheckingAccount(100, 500)` | `balance: 100, overdraft 500` |

> **רמז:** התכונה balance מוגנת, ולכן מחלקה יורשת יכולה להשתמש בה ישירות.

### שלב 4: הכל ביחד

הריצו את `Main`, ובדקו שהפלט זהה לפלט הצפוי. שימו לב שהפעולה `Withdraw` נותנת תוצאה שונה לכל סוג חשבון, אף על פי שהיא מופעלת באותה צורה.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Account a = new Account(100);
        SavingsAccount s = new SavingsAccount(200, 5);
        CheckingAccount c = new CheckingAccount(100, 500);
        Console.WriteLine(a);
        Console.WriteLine(s);
        Console.WriteLine(c);
        Console.WriteLine("account withdraw 300: " + a.Withdraw(300));
        Console.WriteLine("checking withdraw 300: " + c.Withdraw(300));
        Console.WriteLine("checking withdraw 400: " + c.Withdraw(400));
        s.AddInterest();
        Console.WriteLine(s);
        s.Deposit(100);
        Console.WriteLine(s);
        Console.WriteLine(c);
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
