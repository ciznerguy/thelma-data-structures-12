# פרק 6: עצים בינאריים

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **עצים בינאריים**.

## בקצרה

- לחוליה בינארית יש ערך ושני בנים: שמאלי וימני. חוליה בלי בנים היא עלה.
- סריקה בסדר קדם, תוך וסוף, והסריקה לפי רמות בעזרת תור.
- רוב הפעולות על עצים הן רקורסיביות. תנאי העצירה הוא עץ ריק.
- בעץ חיפוש בינארי מחפשים בזמן קצר, כי פוסלים חצי מהעץ בכל צעד.
- גובה העץ, מספר העלים וסכום הערכים מחושבים ברקורסיה.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_BuildTree`: בניית עץ בינארי
2. `Example02_PreOrder`: סריקה בסדר קדם
3. `Example03_InOrder`: סריקה בסדר תוך
4. `Example04_PostOrder`: סריקה בסדר סוף
5. `Example05_CountAndSum`: מספר החוליות וסכום הערכים
6. `Example06_Height`: גובה העץ
7. `Example07_Leaves`: ספירת עלים
8. `Example08_Search`: חיפוש ערך בעץ בינארי רגיל
9. `Example09_SearchTree`: עץ חיפוש בינארי
10. `Example10_LevelOrder`: סריקה לפי רמות

המחלקות של תכנית הלימודים, `Node<T>`, `Queue<T>` ו-`BinNode<T>`, נמצאות בסוף הקובץ, כדי שאפשר יהיה להעתיק קובץ אחד ולהריץ אותו.

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 6](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek06` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 06"
dotnet run
```
