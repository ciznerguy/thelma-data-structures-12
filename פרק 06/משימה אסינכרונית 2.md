# משימה אסינכרונית 2: חיפוש בעץ ועץ חיפוש בינארי

**פרק 6: עצים בינאריים**

> **זמן מוערך: עד 90 דקות.** המשימה מוגשת בסטאקס, וכל הגשה מקבלת ציון.

## איפה עובדים

בסביבת הקוד של סטאקס: **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**. מוחקים את הקוד שנפתח, ומדביקים את השלד שבסעיף **השלד של התוכנית**.

## מבוא

במשימה הזו תחפשו ערכים בעץ רגיל, ותבנו עץ חיפוש בינארי, שבו כל הערכים שבתת העץ השמאלי קטנים מהשורש וכל הערכים שבתת העץ הימני גדולים ממנו. בעץ כזה אפשר לחפש הרבה יותר מהר.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- עובדים עם `BinNode<T>` רק דרך הפעולות שלו: `GetValue`, `GetLeft`, `GetRight`, `SetValue`, `SetLeft`, `SetRight`, `HasLeft`, `HasRight`.
- כל הפעולות על העץ, חוץ מהפעולה `BuildSearchTree`, הן רקורסיביות ואסור להשתמש בהן בלולאות.

## שלבי העבודה

### שלב 1: בניית העץ (כמו במשימה הקודמת)

הפעולה בונה ומחזירה את השורש של העץ הבא:

```text
        8
       / \
      3   10
     / \    \
    1   6    14
```

צרו את החוליות מלמטה למעלה, כשכל חוליה מקבלת את הבנים שלה בבנאי.

חתימה:

```csharp
static BinNode<int> BuildTree()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `BuildTree()` | `((( 1 ) 3 ( 6 )) 8 ( 10 ( 14 )))` |

> **רמז:** הבנאי עם שלושה פרמטרים מקבל בן שמאלי, ערך ובן ימני. לחוליה בלי בן שמאלי מעבירים null.

### שלב 2: חיפוש ערך בעץ רגיל

הפעולה מחזירה אמת אם הערך value נמצא בעץ, ושקר אם לא. בעץ רגיל אין סדר בין הערכים, ולכן הערך יכול להיות בכל מקום: בשורש, בתת העץ השמאלי או בתת העץ הימני.

חתימה:

```csharp
static bool Contains(BinNode<int> root, int value)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `Contains(BuildTree(), 6)` | `True` |
| `Contains(BuildTree(), 7)` | `False` |
| `Contains(null, 1)` | `False` |

### שלב 3: הערך הגדול ביותר

הפעולה מחזירה את הערך הגדול ביותר בעץ רגיל. מניחים שהעץ אינו ריק. עבור חוליה, הערך הגדול ביותר הוא הגדול מבין: ערך החוליה, הגדול ביותר בתת העץ השמאלי (אם יש), והגדול ביותר בתת העץ הימני (אם יש).

חתימה:

```csharp
static int MaxValue(BinNode<int> root)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `MaxValue(BuildTree())` | `14` |
| `MaxValue(new BinNode<int>(5))` | `5` |

> **רמז:** בדקו HasLeft ו-HasRight לפני שקוראים לפעולה על בן.

### שלב 4: ספירת זוגיים

הפעולה מחזירה כמה חוליות בעץ הן בעלות ערך זוגי.

חתימה:

```csharp
static int CountEven(BinNode<int> root)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `CountEven(BuildTree())` | `4` |
| `CountEven(null)` | `0` |

### שלב 5: הוספה לעץ חיפוש

הפעולה מוסיפה את הערך value לעץ חיפוש בינארי, ומחזירה את השורש. אם העץ ריק, מחזירים חוליה חדשה. אם value קטן מהשורש, מוסיפים בתת העץ השמאלי. אחרת מוסיפים בתת העץ הימני. הפעולה רקורסיבית.

חתימה:

```csharp
static BinNode<int> InsertBst(BinNode<int> root, int value)
```

> **רמז:** ההוספה בתת עץ מחזירה את שורש תת העץ, ומשימים אותו בבן המתאים.

### שלב 6: בניית עץ חיפוש

הפעולה מקבלת מערך, ומחזירה עץ חיפוש בינארי שנבנה מהכנסת האיברים לפי הסדר שבמערך, בעזרת הפעולה InsertBst. אפשר להשתמש כאן בלולאה.

חתימה:

```csharp
static BinNode<int> BuildSearchTree(int[] values)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `BuildSearchTree(new int[] { 50, 30, 70, 20, 40 })` | `((( 20 ) 30 ( 40 )) 50 ( 70 ))` |

> **רמז:** התחילו מעץ ריק, כלומר null.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        BinNode<int> root = BuildTree();
        Console.WriteLine("contains 6? " + Contains(root, 6));
        Console.WriteLine("contains 7? " + Contains(root, 7));
        Console.WriteLine("max = " + MaxValue(root));
        Console.WriteLine("even count = " + CountEven(root));
        BinNode<int> bst = BuildSearchTree(new int[] { 50, 30, 70, 20, 40, 60, 80 });
        Console.WriteLine("search tree: " + bst);
        Console.WriteLine("contains 60? " + Contains(bst, 60));
        Console.WriteLine("max = " + MaxValue(bst));
    }

    // כאן כותבים את הפעולות של שלבי העבודה
}
```

הפעולות והמחלקות הבאות מוכנות, ולכן מעתיקים אותן כמו שהן מסוף הקובץ `Program.cs` של הפרק, מתחת לשלד: **`Node`, `Queue`, `BinNode`**.

## הפלט הצפוי

בהרצה של פתרון נכון מתקבל בדיוק הפלט הזה:

```text
contains 6? True
contains 7? False
max = 14
even count = 4
search tree: ((( 20 ) 30 ( 40 )) 50 (( 60 ) 70 ( 80 )))
contains 60? True
max = 80
```

## אתגר רשות

כתבו את הפעולה `SearchSteps(BinNode<int> root, int value)` שמחזירה כמה חוליות נבדקו בחיפוש הערך בעץ חיפוש בינארי, עד שהערך נמצא או עד שהגענו לעץ ריק. בכל צעד הולכים רק לתת עץ אחד. בדקו אותה על עץ החיפוש שבנה `Main`.

| קריאה | תוצאה |
|---|---|
| `SearchSteps(BuildSearchTree(new int[] { 50, 30, 70, 20, 40, 60, 80 }), 60)` | `3` |
| `SearchSteps(BuildSearchTree(new int[] { 50, 30, 70, 20, 40, 60, 80 }), 25)` | `3` |
