## איפה עובדים

בסביבת הקוד של סטאקס: **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**. מוחקים את הקוד שנפתח, ומדביקים את השלד שבסעיף **השלד של התוכנית**.

## מבוא

עץ בינארי הוא מבנה רקורסיבי: שורש, ושני תתי עצים. לכן רוב הפעולות על עצים נכתבות ברקורסיה, כשתנאי העצירה הוא עץ ריק. במשימה הזו תכתבו פעולות שעוברות על עץ וסופרות ומחשבות עליו.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- עובדים עם `BinNode<T>` רק דרך הפעולות שלו: `GetValue`, `GetLeft`, `GetRight`, `SetValue`, `SetLeft`, `SetRight`, `HasLeft`, `HasRight`.
- כל הפעולות על העץ, חוץ מבניית העץ, הן רקורסיביות ואסור להשתמש בהן בלולאות.

## שלבי העבודה

### שלב 1: בניית העץ

הפעולה בונה ומחזירה את השורש של העץ הבא:

```text
        8
       / \
      3   10
     / \    \
    1   6    14
```

צרו את החוליות מלמטה למעלה, כשכל חוליה מקבלת את הבנים שלה בבנאי.

חתימה:

```csharp
static BinNode<int> BuildTree()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `BuildTree()` | `((( 1 ) 3 ( 6 )) 8 ( 10 ( 14 )))` |

> **רמז:** הבנאי עם שלושה פרמטרים מקבל בן שמאלי, ערך ובן ימני. לחוליה בלי בן שמאלי מעבירים null.

### שלב 2: מספר החוליות

הפעולה מחזירה את מספר החוליות בעץ. עץ ריק מכיל 0 חוליות.

חתימה:

```csharp
static int CountNodes(BinNode<int> root)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `CountNodes(BuildTree())` | `6` |
| `CountNodes(null)` | `0` |

> **רמז:** מספר החוליות הוא 1 ועוד מספר החוליות בתת העץ השמאלי ועוד בתת העץ הימני.

### שלב 3: סכום הערכים

הפעולה מחזירה את סכום הערכים של כל החוליות בעץ.

חתימה:

```csharp
static int SumTree(BinNode<int> root)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `SumTree(BuildTree())` | `42` |

### שלב 4: גובה העץ

הפעולה מחזירה את גובה העץ, כלומר מספר הרמות שלו. עץ ריק הוא בגובה 0, ועץ שיש בו רק שורש הוא בגובה 1. הגובה הוא 1 ועוד הגובה הגדול מבין שני תתי העצים.

חתימה:

```csharp
static int Height(BinNode<int> root)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `Height(BuildTree())` | `3` |
| `Height(new BinNode<int>(5))` | `1` |
| `Height(null)` | `0` |

> **רמז:** אפשר להשתמש ב-Math.Max.

### שלב 5: מספר העלים

הפעולה מחזירה כמה עלים יש בעץ. עלה הוא חוליה שאין לה בן שמאלי ואין לה בן ימני.

חתימה:

```csharp
static int CountLeaves(BinNode<int> root)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `CountLeaves(BuildTree())` | `3` |
| `CountLeaves(null)` | `0` |

### שלב 6: הדפסה בסדר תוך

הפעולה מדפיסה את ערכי העץ בסדר תוך: קודם תת העץ השמאלי, אחר כך השורש, אחר כך תת העץ הימני. כל ערך מודפס עם רווח אחריו, והפעולה אינה עוברת שורה.

חתימה:

```csharp
static void InOrder(BinNode<int> root)
```

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        BinNode<int> root = BuildTree();
        Console.WriteLine("tree: " + root);
        Console.WriteLine("nodes = " + CountNodes(root));
        Console.WriteLine("sum = " + SumTree(root));
        Console.WriteLine("height = " + Height(root));
        Console.WriteLine("leaves = " + CountLeaves(root));
        Console.Write("in-order: ");
        InOrder(root);
        Console.WriteLine();
    }

    // כאן כותבים את הפעולות של שלבי העבודה
}
```

הפעולות והמחלקות הבאות מוכנות, ולכן מעתיקים אותן כמו שהן מסוף הקובץ `Program.cs` של הפרק, מתחת לשלד: **`Node`, `Queue`, `BinNode`**.
