# פרק 11: פולימורפיזם

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **פולימורפיזם**.

## בקצרה

- משתנה מסוג האב יכול להצביע על עצם של כל מחלקה יורשת.
- זימון פולימורפי: הפעולה שמתבצעת נקבעת לפי סוג העצם בפועל, בזמן הריצה.
- פעולה עם פרמטר מסוג האב עובדת עם כל המחלקות היורשות.
- המרה כלפי מטה מאפשרת לגשת לפעולות של המחלקה היורשת, אחרי בדיקה של סוג העצם.
- אפשר להוסיף מחלקה יורשת חדשה בלי לשנות את הקוד שכבר כתוב.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_BaseVariable`: משתנה מסוג מחלקת האב
2. `Example02_PolymorphicCall`: זימון פולימורפי
3. `Example03_MixedArray`: מערך מעורב
4. `Example04_BaseParameter`: פרמטר מסוג האב
5. `Example05_ReturnBase`: פעולה שמחזירה סוג אב
6. `Example06_PrintArray`: הדפסת מערך של עצמים
7. `Example07_IsOperator`: בדיקת סוג העצם
8. `Example08_Downcast`: המרה כלפי מטה
9. `Example09_Payroll`: חישוב שכר פולימורפי
10. `Example10_NewSubclass`: הוספת מחלקה חדשה בלי לשנות קוד קיים

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 11](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek11` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 11"
dotnet run
```
