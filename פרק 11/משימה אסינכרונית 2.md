## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: המחלקה Product

כתבו מחלקה `Product` עם תכונות פרטיות `name` ו-`price`, בנאי, פעולות קבלה `GetName` ו-`GetPrice`, פעולה `FinalPrice` שמסומנת `virtual` ומחזירה את המחיר, ודריסה של ההמרה למחרוזת בפורמט `Milk: 8`: שם, נקודותיים והמחיר הסופי.

חתימה:

```csharp
public Product(string name, int price)
public string GetName()
public int GetPrice()
public virtual int FinalPrice()
public override string ToString()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Product("Milk", 8)` | `Milk: 8` |

> **רמז:** ההמרה למחרוזת צריכה להשתמש ב-FinalPrice, ולא ב-GetPrice, כדי שתעבוד נכון גם למוצרים מהמחלקות היורשות.

### שלב 2: מוצר במבצע

כתבו מחלקה `SaleProduct` שיורשת מ-`Product`, עם תכונה פרטית `percent` (אחוז הנחה, מספר שלם). הבנאי מקבל שם, מחיר ואחוז. הפעולה `FinalPrice` נדרסת ומחזירה את המחיר פחות ההנחה, כלומר המחיר פחות (המחיר כפול האחוז, בחלוקה שלמה ב-100). הוסיפו פעולת קבלה `GetPercent`.

חתימה:

```csharp
class SaleProduct : Product
public SaleProduct(string name, int price, int percent) : base(name, price)
public int GetPercent()
public override int FinalPrice()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new SaleProduct("Shirt", 200, 25)` | `Shirt: 150` |
| `new SaleProduct("Shirt", 200, 25).FinalPrice()` | `150` |

### שלב 3: מוצר מיובא

כתבו מחלקה `ImportedProduct` שיורשת מ-`Product`. הפעולה `FinalPrice` נדרסת ומחזירה את המחיר ועוד מס של 17 אחוז, כלומר המחיר ועוד (המחיר כפול 17, בחלוקה שלמה ב-100).

חתימה:

```csharp
class ImportedProduct : Product
public ImportedProduct(string name, int price) : base(name, price)
public override int FinalPrice()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new ImportedProduct("Phone", 1000)` | `Phone: 1170` |

### שלב 4: סך העגלה

כתבו בתוך `Program` פעולה סטטית שמחזירה את סכום המחירים הסופיים של כל המוצרים במערך.

חתימה:

```csharp
static int CartTotal(Product[] cart)
```

### שלב 5: המוצר הזול ביותר

כתבו פעולה סטטית שמחזירה את המוצר שהמחיר הסופי שלו הנמוך ביותר במערך. אם יש כמה כאלה, את הראשון.

חתימה:

```csharp
static Product Cheapest(Product[] cart)
```

### שלב 6: סך ההנחות

כתבו פעולה סטטית שמחזירה את סכום אחוזי ההנחה של המוצרים שבמבצע בלבד. לכל מוצר במערך בדקו, בעזרת `is`, אם הוא `SaleProduct`. אם כן, המירו אותו כלפי מטה בעזרת `(SaleProduct)cart[i]`, והשתמשו ב-`GetPercent`.

חתימה:

```csharp
static int SumOfPercents(Product[] cart)
```

> **רמז:** הפעולה GetPercent קיימת רק ב-SaleProduct, ולכן צריך להמיר לפני שקוראים לה.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Product[] cart = new Product[4];
        cart[0] = new Product("Milk", 8);
        cart[1] = new SaleProduct("Shirt", 200, 25);
        cart[2] = new ImportedProduct("Phone", 1000);
        cart[3] = new SaleProduct("Shoes", 400, 10);
        for (int i = 0; i < cart.Length; i++)
        {
            Console.WriteLine(cart[i]);
        }
        Console.WriteLine("total = " + CartTotal(cart));
        Console.WriteLine("cheapest: " + Cheapest(cart));
        Console.WriteLine("sum of percents = " + SumOfPercents(cart));
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
