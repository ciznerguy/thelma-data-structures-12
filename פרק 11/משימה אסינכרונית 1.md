## איפה עובדים

בסביבת הקוד של סטאקס: **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**. מוחקים את הקוד שנפתח, ומדביקים את השלד שבסעיף **השלד של התוכנית**.

## מבוא

פולימורפיזם פירושו שמשתנה מסוג מחלקת האב יכול להצביע על עצם של כל מחלקה יורשת, והפעולה שמתבצעת נקבעת לפי סוג העצם בפועל. במשימה הזו תכתבו היררכיה של כלי נגינה, ופעולות שעובדות על מערך של כלים בלי לדעת מה סוג כל כלי.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: מחלקת האב Instrument

כתבו מחלקה `Instrument` עם תכונה פרטית `name`, בנאי שמקבל שם, פעולת קבלה `GetName`, פעולה `Play` שמחזירה מחרוזת בפורמט `Flute makes a sound` (השם ואחריו `makes a sound`), ופעולה `GetPrice` שמחזירה 100. שתי הפעולות `Play` ו-`GetPrice` חייבות להיות מסומנות `virtual`.

חתימה:

```csharp
public Instrument(string name)
public string GetName()
public virtual string Play()
public virtual int GetPrice()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Instrument("Flute").Play()` | `Flute makes a sound` |
| `new Instrument("Flute").GetPrice()` | `100` |

### שלב 2: גיטרה ותוף

כתבו מחלקה `Guitar` שיורשת מ-`Instrument`. `Play` שלה מחזירה את השם ואחריו `strums`, והמחיר שלה 500. כתבו מחלקה `Drum`: `Play` שלה מחזירה את השם ואחריו `bangs`, והמחיר שלה 300. לכל מחלקה בנאי שמקבל שם.

חתימה:

```csharp
class Guitar : Instrument
public override string Play()
public override int GetPrice()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Guitar("Fender").Play()` | `Fender strums` |
| `new Drum("Pearl").Play()` | `Pearl bangs` |
| `new Drum("Pearl").GetPrice()` | `300` |

### שלב 3: פסנתר

כתבו מחלקה `Piano` שיורשת מ-`Instrument`. `Play` שלה מחזירה את השם ואחריו `rings`, והמחיר שלה 2000.

חתימה:

```csharp
class Piano : Instrument
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Piano("Yamaha").Play()` | `Yamaha rings` |
| `new Piano("Yamaha").GetPrice()` | `2000` |

### שלב 4: נגינה של כולם

כתבו בתוך `Program` פעולה סטטית שמקבלת מערך של `Instrument` ומדפיסה, בשורה נפרדת לכל כלי, את התוצאה של `Play`.

חתימה:

```csharp
static void PlayAll(Instrument[] band)
```

> **רמז:** הלולאה זהה לכל סוגי הכלים. הפולימורפיזם דואג שכל כלי ינגן בדרך שלו.

### שלב 5: מחיר כולל

כתבו פעולה סטטית שמחזירה את סכום המחירים של כל הכלים במערך.

חתימה:

```csharp
static int TotalPrice(Instrument[] band)
```

### שלב 6: ספירת גיטרות

כתבו פעולה סטטית שמחזירה כמה גיטרות יש במערך. בדקו את סוג העצם בעזרת האופרטור `is`, שמחזיר אמת אם העצם הוא מופע של המחלקה: `band[i] is Guitar`.

חתימה:

```csharp
static int CountGuitars(Instrument[] band)
```

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Instrument[] band = new Instrument[5];
        band[0] = new Guitar("Fender");
        band[1] = new Drum("Pearl");
        band[2] = new Piano("Yamaha");
        band[3] = new Instrument("Flute");
        band[4] = new Guitar("Gibson");
        PlayAll(band);
        Console.WriteLine("total price = " + TotalPrice(band));
        Console.WriteLine("guitars = " + CountGuitars(band));
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
