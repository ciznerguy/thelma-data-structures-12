# משימה אסינכרונית 2: שינוי שרשרת

**פרק 5: שרשרת חוליות**

> **זמן מוערך: עד 90 דקות.** המשימה מוגשת בסטאקס, וכל הגשה מקבלת ציון.

## איפה עובדים

בסביבת הקוד של סטאקס: **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**. מוחקים את הקוד שנפתח, ומדביקים את השלד שבסעיף **השלד של התוכנית**.

## מבוא

במשימה הזו הפעולות משנות את השרשרת: מוסיפות חוליות, מוחקות חוליות ומסדרות מחדש את החיבורים. כל פעולה שעלולה לשנות את החוליה הראשונה מחזירה את הראש החדש, כי השינוי בפרמטר אינו משפיע על המשתנה של מי שקרא לפעולה.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- עובדים עם `Node<T>` רק דרך הפעולות שלו: `GetValue`, `GetNext`, `SetValue`, `SetNext`, `HasNext`.

## שלבי העבודה

### שלב 1: בניית שרשרת

הפעולה מקבלת מערך של מספרים, ומחזירה את החוליה הראשונה של שרשרת חוליות שבה המספרים לפי הסדר שבמערך. אם המערך ריק, מחזירים ריק.

חתימה:

```csharp
static Node<int> BuildChain(int[] values)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `BuildChain(new int[] { 4, 8, 2 })` | `4,8,2,` |

> **רמז:** צרו חוליה ראשונה, ושמרו בנפרד משתנה שמצביע על החוליה האחרונה בשרשרת עד כה. כל חוליה חדשה מחברים אחרי החוליה האחרונה.

### שלב 2: הוספה בסוף

הפעולה מוסיפה חוליה עם הערך value בסוף השרשרת, ומחזירה את הראש. אם השרשרת ריקה, החוליה החדשה היא הראש.

חתימה:

```csharp
static Node<int> AddLast(Node<int> head, int value)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `AddLast(BuildChain(new int[] { 1, 2 }), 3)` | `1,2,3,` |
| `AddLast(null, 7)` | `7,` |

> **רמז:** עוברים עם משתנה עזר עד החוליה שאין אחריה חוליה.

### שלב 3: מחיקת כל המופעים

הפעולה מוחקת מהשרשרת את כל החוליות שהערך שלהן שווה ל-value, ומחזירה את הראש החדש. שימו לב למקרים: כל החוליות הראשונות נמחקות, חוליה באמצע נמחקת, והשרשרת כולה נמחקת.

חתימה:

```csharp
static Node<int> RemoveAll(Node<int> head, int value)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `RemoveAll(BuildChain(new int[] { 5, 2, 5, 3, 5 }), 5)` | `2,3,` |
| `RemoveAll(BuildChain(new int[] { 4, 4 }), 4)` | `` |

> **רמז:** קודם מוחקים את כל החוליות שבהתחלה שערכן value. אחר כך עוברים על השאר ודולגים על כל חוליה שצריך למחוק.

### שלב 4: הוספה לשרשרת ממוינת

השרשרת ממוינת מהקטן לגדול. הפעולה מוסיפה חוליה עם הערך value במקום שישאיר את השרשרת ממוינת, ומחזירה את הראש. שימו לב לסדר החיבורים: קודם מחברים את החוליה החדשה לחוליה שאחריה, ורק אחר כך מחברים אליה את החוליה שלפניה.

חתימה:

```csharp
static Node<int> InsertSorted(Node<int> head, int value)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `InsertSorted(BuildChain(new int[] { 10, 20, 40 }), 30)` | `10,20,30,40,` |
| `InsertSorted(BuildChain(new int[] { 10, 20 }), 5)` | `5,10,20,` |
| `InsertSorted(BuildChain(new int[] { 10, 20 }), 50)` | `10,20,50,` |

### שלב 5: היפוך שרשרת

הפעולה הופכת את סדר החוליות בשרשרת, ומחזירה את הראש החדש. אין ליצור חוליות חדשות: רק משנים את ההפניות של החוליות הקיימות. עוברים על השרשרת ושומרים משתנה שמצביע על החוליה הקודמת. בכל צעד שומרים את החוליה הבאה לפני שמשנים את ההפניה.

חתימה:

```csharp
static Node<int> Reverse(Node<int> head)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `Reverse(BuildChain(new int[] { 1, 2, 3, 4 }))` | `4,3,2,1,` |
| `Reverse(null)` | `` |

> **רמז:** אם לא שומרים את החוליה הבאה לפני שמשנים את ההפניה, מאבדים את שאר השרשרת.

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Node<int> head = BuildChain(new int[] { 5, 2, 5, 3, 5 });
        Console.WriteLine("start: " + head);
        head = AddLast(head, 8);
        Console.WriteLine("after AddLast: " + head);
        head = RemoveAll(head, 5);
        Console.WriteLine("after RemoveAll: " + head);
        Node<int> sorted = BuildChain(new int[] { 10, 20, 40 });
        sorted = InsertSorted(sorted, 30);
        sorted = InsertSorted(sorted, 5);
        sorted = InsertSorted(sorted, 50);
        Console.WriteLine("sorted: " + sorted);
        sorted = Reverse(sorted);
        Console.WriteLine("reversed: " + sorted);
    }

    // כאן כותבים את הפעולות של שלבי העבודה
}
```

הפעולות והמחלקות הבאות מוכנות, ולכן מעתיקים אותן כמו שהן מסוף הקובץ `Program.cs` של הפרק, מתחת לשלד: **`Node`**.
