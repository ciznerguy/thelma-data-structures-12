## מבוא

שרשרת חוליות היא מבנה שבנוי מחוליות, וכל חוליה מצביעה על החוליה הבאה. במשימה הזו תכתבו פעולות שעוברות על שרשרת קיימת וקוראות ממנה מידע, בלי לשנות אותה.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- עובדים עם `Node<T>` רק דרך הפעולות שלו: `GetValue`, `GetNext`, `SetValue`, `SetNext`, `HasNext`.

## שלבי העבודה

### שלב 1: בניית שרשרת

הפעולה מקבלת מערך של מספרים, ומחזירה את החוליה הראשונה של שרשרת חוליות שבה המספרים לפי הסדר שבמערך. אם המערך ריק, מחזירים ריק.

חתימה:

```csharp
static Node<int> BuildChain(int[] values)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `BuildChain(new int[] { 4, 8, 2 })` | `4,8,2,` |

> **רמז:** צרו חוליה ראשונה, ושמרו בנפרד משתנה שמצביע על החוליה האחרונה בשרשרת עד כה. כל חוליה חדשה מחברים אחרי החוליה האחרונה.

### שלב 2: הדפסת שרשרת

הפעולה מדפיסה את ערכי השרשרת בשורה אחת, מופרדים בחץ עם רווח לפניו ואחריו, בפורמט `4 --> 8 --> 2`. אחרי החוליה האחרונה אין חץ. הפעולה מדפיסה גם מעבר שורה בסוף. אם השרשרת ריקה, לא מדפיסים כלום מלבד מעבר השורה.

חתימה:

```csharp
static void PrintChain(Node<int> head)
```

> **רמז:** השתמשו במשתנה עזר שעובר על החוליות, ובפעולה HasNext כדי לדעת אם להדפיס חץ.

### שלב 3: אורך השרשרת

הפעולה מחזירה את מספר החוליות בשרשרת.

חתימה:

```csharp
static int Length(Node<int> head)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `Length(BuildChain(new int[] { 4, 8, 2 }))` | `3` |
| `Length(null)` | `0` |

### שלב 4: סכום הערכים

הפעולה מחזירה את סכום הערכים של כל החוליות.

חתימה:

```csharp
static int Sum(Node<int> head)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `Sum(BuildChain(new int[] { 4, 8, 2 }))` | `14` |

### שלב 5: חיפוש ערך

הפעולה מחזירה את המקום של הערך value בשרשרת, כשהחוליה הראשונה היא במקום 0. אם הערך נמצא כמה פעמים, מחזירים את המקום הראשון. אם הערך לא נמצא, מחזירים מינוס 1.

חתימה:

```csharp
static int PositionOf(Node<int> head, int value)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `PositionOf(BuildChain(new int[] { 4, 8, 2, 8 }), 8)` | `1` |
| `PositionOf(BuildChain(new int[] { 4, 8, 2 }), 5)` | `-1` |

### שלב 6: הערך הגדול ביותר

הפעולה מחזירה את הערך הגדול ביותר בשרשרת. מניחים שהשרשרת אינה ריקה.

חתימה:

```csharp
static int MaxValue(Node<int> head)
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `MaxValue(BuildChain(new int[] { 4, 8, 2 }))` | `8` |

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Node<int> head = BuildChain(new int[] { 5, 12, 8, 3, 20 });
        PrintChain(head);
        Console.WriteLine("length = " + Length(head));
        Console.WriteLine("sum = " + Sum(head));
        Console.WriteLine("position of 8 = " + PositionOf(head, 8));
        Console.WriteLine("position of 99 = " + PositionOf(head, 99));
        Console.WriteLine("max = " + MaxValue(head));
        Node<int> empty = BuildChain(new int[] { });
        Console.WriteLine("empty length = " + Length(empty));
    }

    // כאן כותבים את הפעולות של שלבי העבודה
}
```

הפעולות והמחלקות הבאות מוכנות, ולכן מעתיקים אותן כמו שהן מסוף הקובץ `Program.cs` של הפרק, מתחת לשלד: **`Node`**.
