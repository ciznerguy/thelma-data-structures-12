# פרק 5: שרשרת חוליות

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **שרשרת חוליות**.

## בקצרה

- חוליה מכילה ערך והפניה לחוליה הבאה. החוליה האחרונה מצביעה על ריק.
- שרשרת מיוצגת על ידי משתנה שמצביע על החוליה הראשונה.
- מעבר על שרשרת מתבצע בעזרת משתנה עזר, בלי לשנות את הראש.
- הוספה ומחיקה מצריכות לשים לב לשלושה מקרים: ראש השרשרת, אמצע וסוף.
- החוליה גנרית, ולכן אפשר ליצור שרשרת של כל סוג ערכים.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_BuildChain`: בניית שרשרת חוליות
2. `Example02_Traverse`: מעבר על השרשרת
3. `Example03_LengthAndSum`: אורך השרשרת וסכום הערכים
4. `Example04_Contains`: חיפוש ערך בשרשרת
5. `Example05_AddFirst`: הוספה בהתחלה
6. `Example06_AddLast`: הוספה בסוף
7. `Example07_RemoveValue`: מחיקת ערך
8. `Example08_InsertSorted`: הוספה לשרשרת ממוינת
9. `Example09_ChainOfStrings`: שרשרת של מחרוזות
10. `Example10_RecursiveChain`: פעולה רקורסיבית על שרשרת

המחלקות של תכנית הלימודים, `Node<T>`, נמצאות בסוף הקובץ, כדי שאפשר יהיה להעתיק קובץ אחד ולהריץ אותו.

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 5](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek05` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 05"
dotnet run
```
