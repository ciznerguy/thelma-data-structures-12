## מבוא

במשימה הזו מחלקה מופשטת מגדירה חוזה: כל סוג תשלום חייב לדעת לחשב את העמלה שלו, אבל כל סוג מחשב אותה אחרת. תכתבו את המחלקה המופשטת, שלושה סוגי תשלום, ופעולות שעובדות על מערך של תשלומים בלי לדעת מאיזה סוג כל אחד.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: המחלקה המופשטת

כתבו מחלקה מופשטת `Payment` עם תכונות פרטיות `kind` (מחרוזת, סוג התשלום) ו-`amount` (מספר שלם), בנאי שמקבל את שתיהן, פעולות קבלה `GetKind` ו-`GetAmount`, ופעולה מופשטת `Fee` שמחזירה מספר שלם: העמלה.

חתימה:

```csharp
abstract class Payment
public Payment(string kind, int amount)
public string GetKind()
public int GetAmount()
public abstract int Fee()
```

### שלב 2: תיאור התשלום

הוסיפו ל-`Payment` פעולה רגילה `Describe` שמחזירה מחרוזת בפורמט `cash: 200, fee 0`: הסוג, נקודותיים, הסכום, פסיק, ואז המילה `fee` והעמלה.

חתימה:

```csharp
public string Describe()
```

### שלב 3: שלושה סוגי תשלום

כתבו שלוש מחלקות יורשות. `Cash`, בסוג `cash`, העמלה שלה 0. `Card`, בסוג `card`, העמלה שלה היא הסכום בחלוקה שלמה ב-50. `BankTransfer`, בסוג `transfer`, העמלה שלה היא 5 ועוד הסכום בחלוקה שלמה ב-100. לכל מחלקה בנאי שמקבל רק את הסכום, ומעביר את הסוג והסכום לבנאי של מחלקת האב.

חתימה:

```csharp
class Cash : Payment
public Cash(int amount) : base("cash", amount)
public override int Fee()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Cash(200).Describe()` | `cash: 200, fee 0` |
| `new Card(200).Describe()` | `card: 200, fee 4` |
| `new BankTransfer(1000).Describe()` | `transfer: 1000, fee 15` |

### שלב 4: סך העמלות

כתבו, בתוך `Program`, פעולה סטטית שמקבלת מערך של תשלומים ומחזירה את סכום העמלות.

חתימה:

```csharp
static int TotalFees(Payment[] payments)
```

### שלב 5: העמלה הגבוהה ביותר

כתבו פעולה סטטית שמחזירה את התשלום שהעמלה שלו הגבוהה ביותר במערך. אם יש כמה כאלה, את הראשון שביניהם.

חתימה:

```csharp
static Payment HighestFee(Payment[] payments)
```

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Payment[] payments = new Payment[4];
        payments[0] = new Cash(200);
        payments[1] = new Card(1000);
        payments[2] = new BankTransfer(1000);
        payments[3] = new Card(400);
        for (int i = 0; i < payments.Length; i++)
        {
            Console.WriteLine(payments[i].Describe());
        }
        Console.WriteLine("total fees = " + TotalFees(payments));
        Console.WriteLine("highest: " + HighestFee(payments).Describe());
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
