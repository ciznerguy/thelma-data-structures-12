## מבוא

מחלקה מופשטת מתארת רעיון כללי, ואי אפשר ליצור ממנה עצמים. היא יכולה להגדיר פעולה מופשטת, בלי גוף, שכל מחלקה יורשת חייבת לממש. במשימה הזו תכתבו מחלקה מופשטת של חיה, ושלוש מחלקות שיורשות ממנה.

## כללים

- אסור להשתמש ב: אופרטור התנאי המקוצר, השמות מקוצרות כמו `+=` ו-`-=`, `switch`, `do-while`, `break` ו-`continue`.
- `++` ו-`--` מותרים רק כפקודה בפני עצמה.
- הדפסה רק בעזרת `Console.WriteLine` ו-`Console.Write`.
- אין להשתמש ב-`try/catch`.
- במחרוזות מותרים רק `Length`, גישה לתו לפי מקום, `IndexOf` ו-`Contains`.
- מ-`Math` מותר להשתמש רק ב: `Abs`, `Max`, `Min`, `Pow`, `Round`, `Sqrt`.
- ההערות בעברית בלבד.
- כל התכונות של מחלקה הן `private`, והגישה אליהן היא דרך פעולות `Get` ו-`Set`. לא משתמשים במאפיינים של סי שארפ.

## שלבי העבודה

### שלב 1: המחלקה המופשטת

כתבו את המחלקה `Animal` כמחלקה מופשטת, בעזרת המילה השמורה `abstract`. יש בה תכונה פרטית `name`, בנאי שמקבל שם, פעולת קבלה `GetName`, ופעולה מופשטת `Sound` שמחזירה מחרוזת ואין לה גוף.

חתימה:

```csharp
abstract class Animal
public Animal(string name)
public string GetName()
public abstract string Sound()
```

> **רמז:** פעולה מופשטת נכתבת בלי סוגריים מסולסלים, ונגמרת בנקודה פסיק.

### שלב 2: פעולה רגילה שמשתמשת בפעולה מופשטת

הוסיפו ל-`Animal` פעולה רגילה `Describe` שמחזירה את השם, אחריו המילה `says` בין רווחים, ואחריה הקול, למשל `Rex says woof`. הפעולה משתמשת ב-`Sound`, גם אם אינה יודעת עדיין איך היא ממומשת.

חתימה:

```csharp
public string Describe()
```

### שלב 3: שלוש מחלקות יורשות

כתבו שלוש מחלקות: `Dog` (הקול `woof`), `Cat` (הקול `meow`) ו-`Cow` (הקול `moo`). כל אחת יורשת מ-`Animal`, ומקבלת בבנאי שם ומעבירה אותו לבנאי של מחלקת האב. כל אחת דורסת את `Sound` בעזרת `override`.

חתימה:

```csharp
class Dog : Animal
public Dog(string name) : base(name)
public override string Sound()
```

דוגמאות:

| קריאה | תוצאה |
|---|---|
| `new Dog("Rex").Describe()` | `Rex says woof` |
| `new Cat("Tom").Describe()` | `Tom says meow` |
| `new Cow("Mila").Describe()` | `Mila says moo` |

### שלב 4: מערך של חיות

ב-`Main` יש מערך מסוג `Animal` עם עצמים של המחלקות השונות. כתבו בתוך `Program` פעולה סטטית שמקבלת את המערך ומחזירה כמה חיות הקול שלהן הוא `woof`. השתמשו בפעולה `Sound` ובהשוואת מחרוזות בעזרת `==`.

חתימה:

```csharp
static int CountDogs(Animal[] zoo)
```

## השלד של התוכנית

מדביקים את השלד, ובמקום שמסומן כותבים את הקוד של השלבים. **אין לשנות את** `Main`: הוא מדפיס את הפלט שנבדק.

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Animal[] zoo = new Animal[4];
        zoo[0] = new Dog("Rex");
        zoo[1] = new Cat("Tom");
        zoo[2] = new Cow("Mila");
        zoo[3] = new Dog("Max");
        for (int i = 0; i < zoo.Length; i++)
        {
            Console.WriteLine(zoo[i].Describe());
        }
        Console.WriteLine("dogs = " + CountDogs(zoo));
    }

    // כאן אפשר לכתוב פעולות עזר סטטיות, אם צריך
}

// כאן כותבים את המחלקות של שלבי העבודה
```
