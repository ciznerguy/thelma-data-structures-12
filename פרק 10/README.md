# פרק 10: מחלקה מופשטת

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** בקורס מדעי המחשב באתר קמפוס פותחים את הפרק על **מחלקה מופשטת**.

## בקצרה

- מחלקה מופשטת מתארת רעיון כללי, ואי אפשר ליצור ממנה עצמים.
- פעולה מופשטת מוגדרת בלי גוף, וכל מחלקה יורשת חייבת לממש אותה.
- במחלקה מופשטת יכולות להיות גם תכונות, בנאי ופעולות רגילות.
- משתנה או מערך מסוג המחלקה המופשטת יכול להכיל עצמים של המחלקות היורשות.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_FirstAbstract`: המחלקה המופשטת הראשונה
2. `Example02_AbstractMethod`: פעולה מופשטת
3. `Example03_PartialImplementation`: מימוש חלקי
4. `Example04_Constructor`: בנאי במחלקה מופשטת
5. `Example05_ArrayOfShapes`: מערך של צורות
6. `Example06_TotalArea`: סכום שטחים
7. `Example07_Employees`: עובדים בשכר שונה
8. `Example08_AbstractAnimals`: חיות שמדברות
9. `Example09_Biggest`: הצורה הגדולה ביותר
10. `Example10_Contract`: המחלקה המופשטת כחוזה

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 10](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaDataStructures12.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek10` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 10"
dotnet run
```
