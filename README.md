# מבנה נתונים ותכנות מונחה עצמים בשפת C#

🌐 **לאתר הקורס: [ciznerguy.github.io/thelma-data-structures-12](https://ciznerguy.github.io/thelma-data-structures-12/)**

חומרי לימוד לכיתה י"ב, תיכון תלמה ילין, תשפ"ז. כל פרק הוא קטע קוד עצמאי בשפת C# שאפשר להעתיק, להדביק ולהריץ בסביבת הקוד של סטאקס.

## מה יש כאן

- **12 פרקים** בשני חלקים, עם **120 דוגמאות** מהפשוטה אל המורכבת.
- **22 משימות אסינכרוניות**, שתיים לכל פרק שנלמד השנה. כל משימה עד 90 דקות, ומוגשת בסטאקס.
- **מבחן תרגול** אינטראקטיבי לכל פרק שנלמד, עם ציון לימודי ומשוב. המבחן אינו שומר ואינו שולח דבר.
- למידה מותאמת אישית עם Gemini אחרי כל מבחן.

## איך מריצים בסטאקס

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שנפתח, ומדביקים במקומו את כל התוכן של `Program.cs` של הפרק.
4. לוחצים על כפתור ההרצה. כדי להריץ דוגמה אחת בלבד, מסמנים בהערה את שאר השורות בפעולה `Main`.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

פותחים את `ThelmaDataStructures12.sln`, ולכל פרק יש פרויקט `PerekNN`. לחיצה ימנית על הפרויקט ← **Set as Startup Project** ← **Start**. משורת הפקודה, עם .NET 8:

```bash
cd "פרק 01"
dotnet run
```

## הערות על הקוד

- הקוד נכתב לפי תכנית הלימודים של מדעי המחשב ולפי המגבלות של תכנית הבגרות: בלי אופרטור התנאי המקוצר, השמות מקוצרות, `switch`, `do-while`, `break`, `continue` ו-`try/catch`. במחלקות ניגשים לתכונות פרטיות דרך פעולות `Get` ו-`Set`.
- פלט התוכניות באנגלית, כדי למנוע תצוגה הפוכה בחלון ההרצה.
- המחלקות `Node<T>`, `Queue<T>`, `Stack<T>` ו-`BinNode<T>` הן המחלקות של תכנית הלימודים, והן מצורפות בסוף הקובץ של הפרקים שמשתמשים בהן.
